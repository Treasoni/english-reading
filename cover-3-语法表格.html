语法总结

句首 Doing / Done 三态对比

考研阅读长难句高频结构——句首出现动词-ing 或动词-ed 形式，到底当主语还是状语？看一个关键标志就能判断。

三态对比表

句首形式 标志 语法角色 谓语要求
Doing sth... 无逗号 整串当主语（动名词） 谓语动词死锁单数
Doing sth, S+V+O 有逗号 现在分词作状语 主语 S 须主动发出动作
Done sth, S+V+O 有逗号 过去分词作状语 主语 S 须是被动承受者
❌
无逗号 = 主语
Upgrading home servers requires patience. 谓语锁定单数。
✅
有逗号 + ing = 状语
Following the routine, the student made progress. 主语主动发出。
✅
有逗号 + ed = 状语
Faced with problems, the government acted. 主语被动承受。
解题铁律：看到句首 Doing/Done，第一步找逗号——有逗号是状语（看主被动关系），没逗号是主语（谓语锁单数）。这一个判断就能排除 2-3 个错误选项。
