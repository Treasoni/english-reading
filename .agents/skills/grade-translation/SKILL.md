# Grade Translation

把一篇英语二英译汉翻译练习变成可追踪的批改记录：输入核对 → 图片转写确认（如需）→ 逐句/意群诊断 → 练习性估分 → 修改与参考译文 → 针对性复习 → 保存记录。

## 适用范围

- 批改考研英语（二）英译汉翻译题，通常满分 15 分。
- 用户提交同一篇的修改稿，要求二稿复批或追踪错因。
- 与 [[translate]]（生成阅读文章中英对照翻译）职责分开；不把作文评分规则用于翻译题。
- 英语一翻译不套用本技能的英语二估分口径。用户若提供英语一任务，只能按要求做非评分语义诊断，或先确认另行设计的标准。

## 执行前读取

每次批改前读取以下文件，按其约束执行：

1. `references/english2-translation-scoring-reference.md` — 用户提供评分资料的证据层级、练习性估分档位及不得机械套用的口径。
2. `references/translation-grading-report-template.md` — 单篇报告固定章节。
3. `references/translation-ledger-formats.md` — 错因清单、索引的创建与更新规则。

本技能不建立 workflow 状态文件，不调用网络检索，不把经验性规则升级成官方规定。

## 输入要求

必需：

- 英文原文；
- 用户自己的完整中文译文。

可选：年份/真题来源、话题、题目或参考译文、是否二稿及一稿笔记链接。默认考试类型为英语二。若缺少英文原文或译文，先索取缺失内容；不得仅凭参考答案或记忆推断原文。若话题不能从现有信息可靠判断，评分后保存前询问用户话题，不编造文件名。

## 执行流程

### P0 输入核对

确认原文和译文完整、题型属于英语二英译汉，并读取用户明确指定的一稿笔记（若本次为二稿）。区分用户自译与题目提供的参考译文；后者不能冒充用户作答。

### P1 图片转写（硬门禁）

只要原文或译文来自图片/手写稿：

1. 逐句转写，仅转写、不纠正、不评价；保留原有错字、标点、漏句和原始表达。
2. 不确定内容用 `⟦存疑：推测为 X⟧` 标记，不静默猜测或跳过。
3. 输出完整转写稿后暂停，请用户确认或纠正。未确认前不评分、不统计该处错误、不写正式批改记录。
4. 用户确认后的文本才是批改依据；未确认的存疑处不能用于扣分或定性。

纯文本输入直接作为本轮评分依据，无需重复要求确认。

### P2 全篇阅读与句子切分

先通读整段，识别整体意思、段落逻辑，再按英文句子对齐中文译文；仅在一句含多个独立语义成分时拆成意群帮助解释。列出原文句子并确认每句均有对应译文；发现漏句或无法对齐时明确标注。意群只是诊断单位，不代表官方采分点，也不附加自创的单点分值。

### P3 逐句/意群诊断

逐项对照原文与用户译文，记录：

- 语义状态：准确 / 部分到位 / 误解 / 漏译；
- 主要信息：主干、逻辑关系、关键修饰、并列项、代词指代及上下文关系是否保留；
- 具体问题、对全句理解的影响，以及可执行的改法。

只要译法语义成立，即使与参考译文措辞不同，也判为可接受。参考译文不是唯一标准答案；不把合理的语序调整、意译或汉语省略误判为漏译。

### P4 错因清单

每个可独立说明的问题只归一个主要类别，并额外标一个影响层级：

| 错因类别 | 适用范围 |
|---|---|
| 句法结构与关系 | 主干、从句、修饰范围、逻辑关系或句间关系判断错误 |
| 词义与搭配 | 词义选择、语境义、固定搭配或术语处理不当 |
| 漏译与增译 | 原文信息遗漏，或加入原文不支持的信息 |
| 语义误译 | 译文改变原文核心命题、指代、肯否、比较或因果等意思 |
| 中文表达与语序 | 意思基本正确但中文不通顺、翻译腔重或语序不当 |
| 错别字与标点 | 汉字、标点或明显文字错误 |

影响层级固定为：核心含义错误 / 重要信息偏差 / 局部表达瑕疵。它只说明问题影响，不换算成固定扣分。不得为同一问题重复计数；类别计数必须与错误清单条目数一致。

### P5 练习性估分

1. 先整体读译文，再综合准确性、完整性、通顺度判断档位；不能把错误条目或意群分值相加。
2. 依 `references/english2-translation-scoring-reference.md` 中标明为“用户资料整理的练习参考”的四档给出档位与 15 分制估分。
3. 给出简明判档理由、最影响分数的证据和置信度（高 / 中 / 低）。若单一分数精度会造成误导，另给合理范围并解释不确定来源；分数仍应落在所判档位区间内。
4. 所有分数均标为“练习性估分”，不得声称是官方评分、阅卷实分或精确预测。
5. 不采用资料里无法由官方原件核验的逐句封顶、错别字固定扣分、最小计分单位、每意群分值等规则。更不得自创扣分公式。

### P6 修改与参考译文

- 给一版“最小修改稿”：尽量保留用户可行的表达和结构，只修正已指出的问题；每处修改可回链错误编号。
- 给一版完整参考译文：忠实传达英文原意，中文自然；它仅是可接受的表达示例，不是唯一答案。
- 对原文有歧义、术语存在多种译法或上下文不足的地方，说明不确定性，不用参考译文掩盖。

### P7 针对性复习

围绕本篇最重要或重复出现的问题给 2–3 条可执行自查动作。不默认生成练习题或外部表达库；用户明确要求时再追加。

### P8 保存与跨篇追踪

批改完成后默认在 Vault 保存记录；若用户明确说只在聊天中回答，则不落盘。

1. 单篇笔记：`翻译/<YYYY-MM-DD>-英语二翻译-<话题>-批改.md`；二稿独立为 `...-二稿.md`，读取并链接一稿，不覆盖原稿。文件存在且并非明确二稿时先检查是否同题，存在冲突则询问，不覆盖。
2. 图片输入：将可访问的原图副本保存到 `翻译/素材/`，原文件保留不移动；聊天内图片没有可访问源文件时，在笔记中说明未归档，不伪称已保存。
3. 追加/更新 `翻译/翻译错因清单.md` 和 `翻译/翻译索引.md`，遵循 `references/translation-ledger-formats.md`；所有统计回查单篇笔记。
4. 用户未提供话题且无法可靠概括时，先询问话题后再生成路径与落盘。

## 二稿模式

- 使用与一稿相同的原文；若原文变化，先确认是否仍为同一道题。
- 读取一稿笔记和已确认的一稿译文、评分、错因。
- 独立评分，不以一稿分数作为锚点；报告分数变化及其理由。
- 添加“已解决 / 仍存在或复发 / 新出现”对比；索引分别登记两稿，错因账本按每次提交记录问题表现。
- 笔记文件互相使用 wikilink，保留各自当次译文和评分。

## 保存前自检

- [ ] 必需原文与用户译文齐全；图片转写若有，已得到用户确认。
- [ ] 原文每句均已核对；合理异译没有因词面不同被误判。
- [ ] 每个问题仅计入一个错因类别，影响层级与分值判断没有混为一谈。
- [ ] 分数明确标为练习性估分，档位与分数一致；未使用意群加分或不可信的固定扣分公式。
- [ ] 修改稿真正修复问题；完整参考译文保留原意并标明非唯一答案。
- [ ] 笔记与账本一致；错误计数、分数、稿次和 wikilink 已核对。
- [ ] Obsidian frontmatter 不含嵌套对象；Markdown 表格前有空行；标题格式合法。
