# 批改笔记模板（10 章固定结构）

> 十章标题和顺序固定。小作文先应用下列覆盖规则；大作文直接使用后面的通用骨架。无内容时写「无」，不删章节。

---

## 小作文（A 节）覆盖规则

使用下列字段替换通用 frontmatter 的 `score`、`full_score`、`band`；按题型填写 `essay_type`。以下是已定档示例：

```yaml
full_score: 10
band: "第四档"
score_range: "7–8"
scoring_basis: "2023 年英语二考试大纲 P29–P31，Ⅳ. 写作 A 节"
```

暂不定档时，`band: "暂不定档"`，省略 `score_range`。缺少适用大纲时，`scoring_basis` 写「未使用（缺少适用大纲：{版本或条目}）」。零档按大纲记 `score_range: "0"`，与未定档区分。小作文不写 `score` 字段。

按下列说明替换或增补通用骨架内容，保留十章和三处译文：

- **第一章**：题目原文之后放任务点表，接着放「批改速览」：大纲版本＋练习定档结论（详见第五章）、优先改的 1–3 项及各自的最小改法（引用第四章问题编号）；再放书信或通知的格式与语域核对。

  | 题目要求 | 完成情况 | 原文证据或遗漏点 |
  |----------|----------|------------------|
  | {题目逐项要求} | {已完成 / 部分完成 / 未完成} | {原句或明确的遗漏点} |

- **第四章**：将「原句」列写成「原句或遗漏点」，将「问题说明」列写成「条目与实际影响」，「改法」列给最小修改示例。没有适用大纲时用「诊断依据与实际影响」，不声称失分。表后另放 `### 可选润色（不计入评分）`；润色不计入六类标签统计。
- **第五章**：先注明版本、页码和条目，再填判档证据表。写清本档证据、与上一档的差距（最高档除外）及单项规则的处理。结论只写「练习定档：第四档（7–8/10）」等档次区间；零档写「零档（0/10）」。相邻档待定时写「暂不定档（相邻档难以区分）」和各档依据；缺少适用大纲时写「暂不定档（缺少适用大纲）」及所缺依据，省略判档表、不列候选档。
- **第六、七章**：两版改稿与译文照常；参考重写不作为原稿评分依据。
- **第八章**：标题下直接列优先改的 1–3 项、对应问题编号与动作，没有确需优先修正的则写「无」。不用「从 X 分到 Y 分」句式。
- **二稿对比块**：加「定档结果」行并列记录两稿结论，不算分差。三类问题各逐项列原句／遗漏点、二稿对应证据与下一步；链接旧稿但不回填旧稿。

## 通用 frontmatter

```yaml
---
title: "{YYYY-MM-DD} {类型} {话题} 批改"
type: 作文批改
essay_type: "大作文-柱状图"      # 小作文-书信 / 小作文-通知 / 大作文-柱状图 / 大作文-折线图 / 大作文-饼图 / 大作文-表格
topic: "{话题}"
exam_type: 英语二
prompt_source: "模拟题"          # 或 "2023 年真题"
score: 0                         # 实际得分
full_score: 15                   # 小作文 10，大作文 15
band: "第四档"                   # 第五档 ~ 第一档
word_count: 0
draft: 1                         # 1 = 一稿，2 = 二稿
tags:
  - 作文
  - 作文批改
  - 英语二
created: {YYYY-MM-DD}
updated: {YYYY-MM-DD}
sources: "素材/{同名}.jpg"
---
```

## 正文骨架

```markdown

## 一、题目解析与任务点清单

题目原文：

> {题目英文原文}

任务点：

- [x] 任务点 1
- [ ] 任务点 2

格式要求（小作文）：

- [x] 称呼 / 结束语 / 署名 / 语域

## 二、原文转写

> 保留原始拼写与语法错误，未做任何纠正。

{逐段英文}

- 字数：{n} 词（要求约 {m} 词）
- 存疑处：{若有，逐条列出}

### 参考译文

> 按确认后的转写稿字面翻译。语法错误、逻辑跳跃、中式表达都保留，不在译文里代为修正。未确认的存疑处保持 `⟦存疑⟧`，不译成确定措辞。

{逐段中文，与上面英文逐段对应}

| 段落 | 功能 | 主题句 | 衔接手段 | 任务点落位 |
|------|------|--------|----------|------------|

## 四、错误清单

| # | 原句 | 错因标签 | 问题说明 | 改法 |
|---|------|----------|----------|------|

标签计数：内容要点缺失 {n} · 语言准确性 {n} · 词汇与搭配 {n} · 句式与衔接 {n} · 篇章结构 {n} · 字数与格式 {n}

| 评分维度 | 标准档位描述（引用） | 本篇表现 |

{保留原句型与结构，只修错}
```

## 格式规范

- 表格前必须留空行，否则 Obsidian 渲染异常
- 不嵌套 callout；需要提示时用 `> [!tip]` 或 `> [!warning]` 单层
- 章节标题用 `## 一、` 至 `## 十、`，不使用 `####` 堆叠
- 英文原句与改稿保持原样，不用斜体替代引号
- `### 参考译文` 只作为第二、六、七章的子小节，不升成一级章节，十章顺序不变
- 第二章译文跟着确认后的转写稿，不修正原文错误；第六、七章译文跟着对应改稿，不另写概述
