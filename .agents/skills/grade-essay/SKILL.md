# Grade Essay

把一篇英语二作文（手写图片或文本）变成一份可追踪的批改笔记：转写确认 → 任务点核对 → 结构分析 → 错误归类 → 定档评分 → 双版本改稿 → 提分路径 → 落盘累积。

## When to Use

- 作文批改 / 批改我的作文 / 给这篇作文打分
- 英语二小作文（书信、通知）或大作文（柱状图、折线图、饼图、表格）
- 二稿重批（改完再交一次，看提分与错因复发）
- 作文提分建议 / 结构分析

不要用本技能：

- 阅读 Passage 精读 → `generate-reading-note`
- 完形填空精读 → `generate-cloze-note`
- 单步翻译、单词辨析、阅读技巧 → 对应技能
- 英语一作文：当前未内置标准，收到时先向用户确认是否按英语二标准近似处理

| Runtime | Skill Dir |

## Preflight

1. 确认 `.learnings/` 经验库已加载（会话启动时注入，缺失再读）。
2. 读 `references/english2-scoring-criteria.md`——唯一评分依据。小作文在 P5 核对用户指定版本及适用条目；依据不可用时走「不定档，只诊断」分支。
3. 读 `references/essay-report-template.md` 与 `references/ledger-formats.md`——固定产出格式。
4. 不创建 workflow 状态文件，不修改 `.claude/workflows/`。
5. **不得改写评分标准文件**，除非用户当次提供了大纲原图或官方 PDF，且明确要求按该原文更新。检索摘要、网页转述、模型记忆都不是来源。

## 评分标准文件门禁

`references/english2-scoring-criteria.md` 是只读评分依据，不是本技能的可编辑产物。

- 定档、给分、扣分只引用该文件已有原文。文件里没有的规则，评分时不得使用，也不得补写进去。
- 需要更新标准时：先向用户索取大纲原图或官方 PDF；没有原文就停止，不检索后自行起草。
- WebSearch 若返回 `<｜｜DSML｜｜>` 之类标记，判定无搜索后端，不重试。定位来源只用 `curl` + cn.bing.com / so.com / wap.sogou.com，且检索结果只用于找到文件，不写入标准正文。
- 允许更新时：档位描述保持大纲句式，不改写成「包含所有内容要点」「无法辨认才处理」之类复述；书写、抄题、长度只保留大纲原规则，不发明百分比或分值公式。
- 每次改动必须在该文件「来源与校订记录」追加一行：日期、官方来源、改了哪句。被拒绝的网页说法也记一行，并写明拒绝理由。
- `.claude` 与 `.agents` 两份标准文件必须同时改，改完用 `diff -q` 确认一致。

## Input Contract

必填：

- 作文题目：文字、截图或图片路径；若只给图片，题目文字也要转写进笔记
- 你的作答：手写图片路径，或直接粘贴的英文文本

可选（缺失时按默认值，并在笔记中注明假设）：

| 参数 | 默认 |
|------|------|
| 考试类型 | 英语二 |
| 作文类型 | 小作文-书信 / 小作文-通知 / 大作文-柱状图 / 大作文-折线图 / 大作文-饼图 / 大作文-表格（无法判定时问用户） |
| 题目来源 | 模拟题；真题则记录年份 |
| 是否二稿 | 否 |

## 执行流程

### P0 输入确认

核对题目、作答、类型、来源。缺题目或缺作答时直接问，不要猜。小作文在诊断前按 P5 第 1 条确认本次适用的大纲版本与可用依据。

### P1 转写（硬门禁）

逐段输出英文转写稿，只做转写，不做评价：

- **保留原文一切拼写、语法、标点错误，禁止静默纠正**
- 笔迹含糊处标 `⟦存疑：推测为 X⟧`，不得跳句
- 结尾给出字数统计，并对照要求字数（小作文约 100 词，大作文约 150 词）

输出后**停下**，等用户确认或纠正。未确认不得进入 P2。用户改过的版本即为评分依据。

确认后的转写稿同时是第二章 `### 参考译文` 的英文底稿。未确认的 `⟦存疑：推测为 X⟧` 不得译成确定措辞，也不得据此扣分。

### P2 题目解析

把题目拆成必须覆盖的任务点清单：

- 小作文：逐项写「题目要求｜已完成 / 部分完成 / 未完成｜原文证据或遗漏点」。另核对文体与语域：书信检查称呼、结束语、署名及其与收信人关系的匹配；通知检查标题、发布身份、面向的读者和语气，按题面与情境判断日期、署名等是否需要。题目明示要求与常见写法分开，不把模板惯例当作必写项。
- 大作文：图表描述要素（趋势、关键数据、对比、极值）+ 原因分析 + 结论或建议，输出为可勾选清单。

P4 逐点对账。

### P3 结构与段落分析

逐段给出：段落功能、是否有主题句、句间衔接手段、任务点落位。最后给一段整体结构判断（结构是否服务于题目要求，而不是套模板）。

### P4 错误清单

表格四列：`原句 | 错因标签 | 问题说明 | 改法`。每处失分**只归一类**，标签固定为下列 6 种：

| 标签 | 覆盖内容 |
|------|----------|
| 内容要点缺失 | 漏任务点、图表信息缺描述（趋势、数据、对比） |
| 语言准确性 | 语法、时态、主谓一致、冠词、单复数 |
| 词汇与搭配 | 词不达意、搭配错误、拼写、中式英语 |
| 句式与衔接 | 简单句堆砌、连接词单一、指代不清、段落无过渡 |
| 篇章结构 | 缺主题句、段落功能混乱、开头结尾缺失 |
| 字数与格式 | 字数不足或超限、书信格式、语域不当、整句照搬题干 |

表格行数必须等于各标签计数之和。中式英语在「问题说明」列标注 `#中式`；大作文整句照搬题干时标 `#抄题`，小作文按 P5 的抄题范围标注，均不单列标签。

**小作文的入表条件**：上表用于归类，不是扣分标准。每行写「确认的原句或遗漏的题目要点 → 对应大纲条目及实际影响 → 最小可行改法」（给替换句或补写示例）。简单但正确、得体且满足任务的表达不因不够复杂而列错；语言多样性按 A 节和具体题目判断。可选润色另列，不计入标签统计或判档。缺少适用大纲时，只列能由原文和题目证实的诊断，不称为失分；可按六类归档确实的问题。

### P5 评分

严格按 `references/english2-scoring-criteria.md` 中适用的大纲条目执行，按 A / B 节分支。参考文件里的档内选分步骤和输出示例不用于 A 节报告。

#### 小作文（A 节）：档次与区间

1. **先核对依据**。未指定版本时，默认用现有参考注明的 2023 年英语二考试大纲 P29–P31「Ⅳ. 写作」A 节；真题年份单独记录。每次注明实际使用的版本、页码和对应条目（A 节侧重、所用档位描述、适用单项），并引用原文措辞。若用户指定版本无法从参考核对，或缺少完成判档所需的适用条目，标明「暂不定档（缺少适用大纲）」，说明缺的是哪个版本或条目，并给诊断和改法；不以旧版代评、不报候选档或分数。
2. **整体定档**。按 A 节侧重，将任务点覆盖、组织连贯、语言准确、文体格式与语域对照档位描述，引用原句或指出遗漏；语言多样性结合具体题目。写明为何落在此档、为何未到上一档（最高档不需比较）。若确实不能可靠区分两个相邻档，标明「暂不定档（相邻档难以区分）」，给出两个候选档、各自依据及分界条目，不合并区间。
3. **单项规则单列**，不重复计入：书写较差且实际影响理解才降一档，写出可核对的证据和调整前后档次；仅有文本说明无法评估书写。抄题指明与指导语或提示信息重合的部分或整个语句（个别关键词不算），标 `#抄题`；长度写实际词数、目标和差距。「酌情扣分」只作定性说明，不自设字数阈值、扣分值或自动降档。拼写与标点按对交际的影响计入语言准确性，英、美拼写及用法均可接受。
4. **报告结论**。能定档时只报告所定档和大纲对应区间（零档为 `0/10`），标为练习定档，不选档内单点分数，不拆项加总。相邻档待定与依据缺失分别记录；不得把「暂不定档」记成零档。

#### 大作文（B 节）：原有评分流程

1. 先**按内容和语言定档**（大纲原文：先确定所属档次），判断落在第五档至零档中的哪一档，不是逐项加分
2. 再**按该档要求给分**：描述项全部达标取档内高分，有明显短板取档内低分
3. 单项规则按大纲处理，全部单列说明、不重复计入定档：
   - 书写较差以致影响读者理解 → **降低一个档次**
   - 整句照搬题干或提示信息 → 酌情扣分（错误清单标 `#抄题`）
   - 文章长度不符合要求 → 酌情扣分（写明实际词数与要求值差距）
   - 拼写与标点 → 计入语言准确性；英式、美式拼写均可接受
4. 判档依据表三列：`评分维度 | 标准档位描述（引用原文措辞） | 本篇表现`

禁止：

- 把总分拆成维度分值相加（如 5+5+5），官方无此权重
- 因「观点我不认同」影响分数
- 引用标准文件之外的扣分经验
- 在评分章节出现「我觉得 / 建议 / 更好的写法」——那是 P7 的内容

### P6 改稿

- **改稿 A｜最小改动版**：保留你的原句型和段落结构，只修错，目标是不掉分
- **改稿 B｜高分重写版**：重构衔接与表达，目标冲上一档；逐处标注改动理由

两版都必须覆盖 P2 的全部任务点，不得换题。

三处译文都是子小节，不新增一级章节：

- 第二章 `### 参考译文`：按确认后的转写稿**字面翻译**。语法错误、逻辑跳跃、中式表达都保留，不在译文里代为修正。
- 第六章、第七章各加 `### 参考译文`：与对应改稿**逐句对应**。改稿改了哪句，译文就跟着哪句，不另写一篇概述。

### P7 提分路径

- 小作文：从 P4 选最优先改的 1–3 项（无则写「无」），按对完成任务和理解的影响排序，每项给出可执行动作和对应问题编号。批改摘要先给任务点，再给定档结论和优先改法；不承诺分数或升档。
- 大作文：从 X 分到 Y 分只需改 3 件事，按投入产出排序，每条给出可执行动作
- 可迁移表达 5–8 个，只从你写的句子升级而来，含原句 → 升级句 → 适用场景
- 复批自查 3 条，下次动笔前先看

### P8 落盘

按 `references/ledger-formats.md` 执行：

1. 写批改笔记：`作文/<YYYY-MM-DD>-<类型>-<话题>-批改.md`
2. 原图归档：`作文/素材/<同名>.jpg`（文本输入则跳过）
3. 追加 `作文/作文错因清单.md`：篇目行 + 6 类标签计数更新
4. 追加 `作文/高分表达库.md`：按功能分类
5. 更新 `作文/作文索引.md`

### 二稿模式

收到同一题目的二次批改时：

1. 读取该题目上一版笔记
2. 在 P5 后追加对比表：`维度 / 一稿 / 二稿 / 变化`
3. 输出三列清单：已解决、仍存在、新出现
4. 二稿笔记独立成文，文件名加 `-二稿`。小作文在新稿链接旧稿，不回改旧笔记；并列记录两稿原有结论，旧稿若只有单点则标为历史记录，不补推档次或算分差。「已解决／仍存在／新出现」逐项对照证据和下一步，不只列计数。大作文保持两篇互相 wikilink、不覆盖一稿的原规则。
