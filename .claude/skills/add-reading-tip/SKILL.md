# 添加阅读心得技能 (add-reading-tip)

向 `阅读心得.md` 文件添加新的阅读技巧条目，保持统一的格式和结构。

## 前置条件

输出遵循 Obsidian Flavored Markdown 规范。参考：
- `obsidian-markdown` 技能 — 完整语法

## 输入

用户提供：

1. **技巧名称** — 简短的技巧标题
2. **核心要点** — 一句话概括技巧核心
3. **应用场景**（可选） — 适用的场景或情况
4. **操作步骤**（可选） — 具体执行步骤
5. **示例**（可选） — 真题示例或说明

## 工作流

### 步骤 1：读取现有内容

- 读取 `阅读心得.md` 文件
- 定位到 `## 四、更多阅读技巧` 部分
- 找到现有的条目数量（查找 `### 4.` 开头的标题）
- 确定新条目的编号（如有 4.1、4.2，则新条目为 4.3）

### 步骤 2：收集技巧信息

向用户提问以下内容（如未提供）：

1. **技巧名称**：请提供技巧的简短标题
2. **核心要点**：一句话概括这个技巧的核心
3. **应用场景**（可选）：这个技巧适用于什么情况？
4. **操作步骤**（可选）：具体如何执行这个技巧？
5. **示例**（可选）：有没有真题示例或具体说明？

### 步骤 3：生成条目内容

按照以下模板格式生成新条目：

```markdown
### 4.X 技巧名称

> [!tip] 核心要点
> 一句话概括这个技巧的核心

**应用场景**：
- 场景1
- 场景2

**操作步骤**：
1. 第一步
2. 第二步

**示例**：
- 示例说明
```

根据用户提供的信息灵活调整：
- 如果没有应用场景，省略该部分
- 如果没有操作步骤，省略该部分
- 如果没有示例，省略该部分

### 步骤 4：插入到文件

- 找到 `## 四、更多阅读技巧` 部分的末尾
- 在最后一个条目（或模板占位符）之后插入新条目
- 用 `---` 分隔线分隔新旧条目
- 用 Edit 工具执行插入操作
- 更新 YAML frontmatter 的 `updated` 时间戳

### 步骤 5：验证

- 报告添加成功
- 显示新条目的内容预览
- 向用户确认操作完成

## 输出格式

新条目以 Obsidian callout 格式插入到 `阅读心得.md` 的第四部分。

核心约定：
- 使用 `> [!tip]` callout 包裹核心要点
- 保持与现有条目一致的格式风格
- 每个条目用 `---` 分隔线分隔

## 约束

- 不修改现有的条目内容
- 保持与现有条目一致的格式风格
- 新条目编号递增（4.1 → 4.2 → 4.3 ...）
- 若用户未提供核心要点，必须询问，不可省略
- 插入位置必须在第四部分的末尾，不可插入到其他位置

## 相关技能

此技能用于维护阅读心得积累：
- `阅读心得.md` — 阅读技巧笔记文件
