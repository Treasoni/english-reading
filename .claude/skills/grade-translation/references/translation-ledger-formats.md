# 翻译批改常驻账本格式

> 常驻文件位于 Vault 根目录的 `翻译/`。单篇笔记是详细内容的唯一来源；账本只做跨篇索引与统计。每次新建或复批一稿，都登记一次。

## 一、翻译错因清单

文件：`翻译/翻译错因清单.md`

首次创建时使用以下结构：

```markdown
---
title: 翻译错因清单
type: 翻译错因清单
exam_type: 英语二
updated: {YYYY-MM-DD}
tags:
  - 翻译
  - 错因
---

# 英语二翻译错因清单

> 跨篇累积。每条问题只计入一个主要类别；二稿按本次提交重新登记，方便追踪已解决、复发与新问题。

## 批次登记

| 日期 | 话题 | 稿次 | 分数/15 | 档位 | 主要问题 | 批改笔记 |
|---|---|---:|---:|---|---|---|

## 错因统计

| 错因类别 | 累计问题数 | 涉及稿次数 | 常见表现 | 建议自查 |
|---|---:|---:|---|---|
| 句法结构与关系 | 0 | 0 | | |
| 词义与搭配 | 0 | 0 | | |
| 漏译与增译 | 0 | 0 | | |
| 语义误译 | 0 | 0 | | |
| 中文表达与语序 | 0 | 0 | | |
| 错别字与标点 | 0 | 0 | | |

## 复发重点

1. {类别/表现} —— {累计次数} 次，见 {相关笔记链接}
```

更新规则：

- 每一稿在“批次登记”追加一行；稿次分别登记，旧记录不覆盖。
- 统计数按每份单篇笔记“错误清单”的条目数累计；同一问题不重复归类。
- “涉及稿次数”只在该类别本稿至少出现一条时加 1；二稿是新的稿次。
- 更新代表性表现与复发重点时保留对应笔记 wikilink，便于回查原句。
- 完成前核对：累计问题数等于已登记单篇笔记中各错因清单条目的总数；涉及稿次不超过已登记稿次数。

## 二、翻译索引

文件：`翻译/翻译索引.md`

首次创建时使用以下结构：

```markdown
---
title: 翻译索引
type: 翻译索引
exam_type: 英语二
updated: {YYYY-MM-DD}
tags:
  - 翻译
  - 索引
---

# 英语二翻译批改索引

## 批改记录

| 日期 | 话题 | 来源/年份 | 稿次 | 分数/满分 | 练习档位 | 置信度 | 笔记 |
|---|---|---|---:|---|---|---|---|

## 月度趋势

| 月份 | 批改稿数 | 平均分/15 | 主要错因 | 备注 |
|---|---:|---:|---|---|
```

更新规则：

- 每次提交都追加记录，包括二稿；链接到对应单篇批改笔记。
- 月均分只作本人练习趋势参考，不与不同评分模型或年份的真实阅卷成绩等同。
- 估分范围只在单篇报告中保留；索引记单一估分，并由单篇笔记保存置信度与范围。
- `updated` 与本次日期同步；确保索引分数和报告一致。

## 三、命名与图片归档

- 一稿：`翻译/<YYYY-MM-DD>-英语二翻译-<话题>-批改.md`
- 二稿：`翻译/<YYYY-MM-DD>-英语二翻译-<话题>-二稿.md`
- 图片副本：`翻译/素材/<YYYY-MM-DD>-英语二翻译-<话题>-原图.<原扩展名>`
- 归档只复制可访问的原图，不移动或重命名原文件；文本输入不创建素材副本。
- 文件名冲突时先检查是不是同题二稿；无法确认时询问，不覆盖旧笔记。
