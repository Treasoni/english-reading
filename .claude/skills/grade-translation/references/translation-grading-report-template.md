# 翻译批改报告模板

> 报告章节固定。未发生的分支注明“无”或“本篇不适用”，不伪造内容。评分明确标为练习性估分。

## Frontmatter

```yaml
---
title: "{YYYY-MM-DD} 英语二翻译 {话题} 批改"
type: 翻译批改
exam_type: 英语二
topic: "{话题}"
source_year: "{年份或未知}"
score: 0
full_score: 15
practice_band: "第 2 档"
confidence: 中
draft: 1
created: {YYYY-MM-DD}
updated: {YYYY-MM-DD}
tags:
  - 翻译
  - 翻译批改
  - 英语二
sources: "{题目原文来源或图片档案路径；无则写文本输入}"
---
```

## 格式要求

- 英文原文与确认译文完整保存，避免只存错误片段。
- 允许将逐句核对改用表格，但句子太长时用分句小节，避免横向表格过宽。
- 所有表格前留空行；frontmatter 不使用嵌套对象；标题 `#` 后留空格。
- 图片转写存疑若已确认，记录最终确认文本；未确认时不进入正式评分笔记。
