# Grade Essay

把一篇英语二作文（手写图片或文本）变成一份可追踪的批改笔记：转写确认 → 任务点核对 → 结构分析 → 错误归类 → 定档评分 → 双版本改稿 → 提分路径 → 落盘累积。

## When to Use

- 作文批改 / 批改我的作文 / 给这篇作文打分
- 英语二小作文（书信、通知）或大作文（柱状图、折线图、饼图、表格）
- 二稿重批（改完再交一次，看提分与错因复发）
- 作文提分建议 / 结构分析

不要用本技能：

- 阅读 Passage 精读 → `generate-reading-note`
- 完形填空精读 → `generate-cloze-note`
- 单步翻译、单词辨析、阅读技巧 → 对应技能
- 英语一作文：当前未内置标准，收到时先向用户确认是否按英语二标准近似处理

## Preflight

1. 确认 `.learnings/` 经验库已加载（会话启动时注入，缺失再读）。
2. 读 `references/english2-scoring-criteria.md`——评分**只允许**依据该文件。
3. 读 `references/essay-report-template.md` 与 `references/ledger-formats.md`——固定产出格式。
4. 不创建 workflow 状态文件，不修改 `.claude/workflows/`。

## Input Contract

必填：

- 作文题目：文字、截图或图片路径；若只给图片，题目文字也要转写进笔记
- 你的作答：手写图片路径，或直接粘贴的英文文本

可选（缺失时按默认值，并在笔记中注明假设）：

| 参数 | 默认 |
|------|------|
| 考试类型 | 英语二 |
| 作文类型 | 小作文-书信 / 小作文-通知 / 大作文-柱状图 / 大作文-折线图 / 大作文-饼图 / 大作文-表格（无法判定时问用户） |
| 题目来源 | 模拟题；真题则记录年份 |
| 是否二稿 | 否 |

## 执行流程

### P0 输入确认

核对题目、作答、类型、来源。缺题目或缺作答时直接问，不要猜。

### P1 转写（硬门禁）

逐段输出英文转写稿，只做转写，不做评价：

- **保留原文一切拼写、语法、标点错误，禁止静默纠正**
- 笔迹含糊处标 `⟦存疑：推测为 X⟧`，不得跳句
- 结尾给出字数统计，并对照要求字数（小作文约 100 词，大作文约 150 词）

输出后**停下**，等用户确认或纠正。未确认不得进入 P2。用户改过的版本即为评分依据。

### P2 题目解析

把题目拆成必须覆盖的任务点清单：

- 小作文：信息点逐条列出 + 格式要求（称呼、正文、结束语、署名）+ 语域（正式/非正式）
- 大作文：图表描述要素（趋势、关键数据、对比、极值）+ 原因分析 + 结论或建议

输出为可勾选清单，供 P4 逐点对账。

### P3 结构与段落分析

逐段给出：段落功能、是否有主题句、句间衔接手段、任务点落位。最后给一段整体结构判断（结构是否服务于题目要求，而不是套模板）。

### P4 错误清单

表格四列：`原句 | 错因标签 | 问题说明 | 改法`。每处失分**只归一类**，标签固定为下列 6 种：

| 标签 | 覆盖内容 |
|------|----------|
| 内容要点缺失 | 漏任务点、图表信息缺描述（趋势、数据、对比） |
| 语言准确性 | 语法、时态、主谓一致、冠词、单复数 |
| 词汇与搭配 | 词不达意、搭配错误、拼写、中式英语 |
| 句式与衔接 | 简单句堆砌、连接词单一、指代不清、段落无过渡 |
| 篇章结构 | 缺主题句、段落功能混乱、开头结尾缺失 |
| 字数与格式 | 字数不足或超限、书信格式、语域不当 |

表格行数必须等于各标签计数之和。中式英语在「问题说明」列标注 `#中式`，不单列标签。

### P5 评分

严格按 `references/english2-scoring-criteria.md` 执行：

1. 先整体定档：对照档位描述，判断落在哪一档（不是逐项加分）
2. 再档内定分：描述全部达标取档内高分，有明显短板取档内低分
3. 字数与格式问题按文件中的规则单独说明扣分，不重复计入档位判断
4. 判档依据表三列：`评分维度 | 标准档位描述（引用原文措辞） | 本篇表现`

禁止：

- 把总分拆成维度分值相加（如 5+5+5），官方无此权重
- 因「观点我不认同」影响分数
- 引用标准文件之外的扣分经验
- 在评分章节出现「我觉得 / 建议 / 更好的写法」——那是 P7 的内容

### P6 改稿

- **改稿 A｜最小改动版**：保留你的原句型和段落结构，只修错，目标是不掉分
- **改稿 B｜高分重写版**：重构衔接与表达，目标冲上一档；逐处标注改动理由

两版都必须覆盖 P2 的全部任务点，不得换题。

### P7 提分路径

- 从 X 分到 Y 分只需改 3 件事，按投入产出排序，每条给出可执行动作
- 可迁移表达 5–8 个，只从你写的句子升级而来，含原句 → 升级句 → 适用场景
- 复批自查 3 条，下次动笔前先看

### P8 落盘

按 `references/ledger-formats.md` 执行：

1. 写批改笔记：`作文/<YYYY-MM-DD>-<类型>-<话题>-批改.md`
2. 原图归档：`作文/素材/<同名>.jpg`（文本输入则跳过）
3. 追加 `作文/作文错因清单.md`：篇目行 + 6 类标签计数更新
4. 追加 `作文/高分表达库.md`：按功能分类
5. 更新 `作文/作文索引.md`

### 二稿模式

收到同一题目的二次批改时：

1. 读取该题目上一版笔记
2. 在 P5 后追加对比表：`维度 / 一稿 / 二稿 / 变化`
3. 输出三列清单：已解决、仍存在、新出现
4. 二稿笔记独立成文，不覆盖一稿；文件名加 `-二稿`，两篇互相 wikilink

## 自检清单（提交前逐条过）

- [ ] 转写稿与用户确认版本一致，未被静默纠正
- [ ] 错因清单行数 = 6 类标签计数之和
- [ ] 分数落在所定档位区间内
- [ ] 判档依据逐条引用标准措辞，无自造标准
- [ ] 评分章无主观建议，改稿章无未引用的分数
- [ ] 改稿 A、B 都覆盖全部任务点
- [ ] 表格前留空行；无嵌套 callout
- [ ] 四个常驻文件（笔记、错因清单、表达库、索引）均已更新
- [ ] frontmatter 字段完整，未使用嵌套对象
