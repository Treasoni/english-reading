# 常驻文件格式（错因清单 / 表达库 / 索引）

> 三个文件位于 `作文/` 根目录，跨篇累积。每次批改后按本文件更新，不改变表结构。

新小作文在错因清单「分数」和索引「分数/满分」列写区间，例如 `7–8/10`，「档位」列写 `第四档`；零档写 `0/10` 和 `零档`。暂不定档时这两列分别写 `—` 与 `暂不定档`，原因留在批改笔记。不改历史记录；小作文行只统计确实的问题，不计入可选润色。

```markdown
# 作文错因清单

> 跨篇累积。每处失分只归一类，六类标签固定：内容要点缺失 / 语言准确性 / 词汇与搭配 / 句式与衔接 / 篇章结构 / 字数与格式。

## 篇目登记

| 日期 | 篇目 | 类型 | 分数 | 档位 | 主要失分（3 条） |
|------|------|------|------|------|------------------|

## 标签统计

| 标签 | 累计次数 | 涉及篇数 | 典型例句 | 改法要点 |
|------|----------|----------|----------|----------|
| 内容要点缺失 | 0 | 0 | | |
| 语言准确性 | 0 | 0 | | |
| 词汇与搭配 | 0 | 0 | | |
| 句式与衔接 | 0 | 0 | | |
| 篇章结构 | 0 | 0 | | |
| 字数与格式 | 0 | 0 | | |

## 复发榜

按「累计次数 / 涉及篇数」降序，列前 3：

1. {标签} —— {次数} 次，{篇数} 篇
```

更新规则：

- 篇目登记每次批改追加一行
- 标签统计的「累计次数」累加本次错误清单中该标签的行数
- 「涉及篇数」：该标签在本篇出现 ≥1 次则 +1
- 「典型例句」只在新出现更典型例句时替换
- 计数必须等于各篇错误清单行数之和，提交前核对

- 已在考场可用的表达，标记 ✅；仍不熟练的标记 ⏳

## 三、作文索引.md

```markdown
---
title: 作文索引
type: 作文索引
updated: {YYYY-MM-DD}
tags:
  - 作文
  - 索引
---

# 作文索引

| 日期 | 类型 | 话题 | 分数/满分 | 档位 | 稿次 | 笔记 |
|------|------|------|-----------|------|------|------|

## 分数趋势

| 月份 | 篇数 | 平均分率 | 主要失分标签 |
|------|------|----------|--------------|
```

说明：

- 大作文「分数/满分」列沿用 `11/15`；小作文按上文登记。
- 「平均分率」沿用精确分数 ÷ 满分，只纳入有实际单点分数的记录。新小作文（包括零档和暂不定档）不进入该均值，不取区间中点、不折算或记作零；月度篇数与主要失分标签仍按实际记录统计。无单点分数时填 `—`。
- 索引只登记，不参与评分
