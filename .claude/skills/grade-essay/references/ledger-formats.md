# 常驻文件格式（错因清单 / 表达库 / 索引）

> 三个文件位于 `作文/` 根目录，跨篇累积。每次批改后按本文件更新，不改变表结构。

---

## 一、作文错因清单.md

```markdown
---
title: 作文错因清单
type: 作文错因清单
exam_type: 英语二
updated: {YYYY-MM-DD}
tags:
  - 作文
  - 错因
---

# 作文错因清单

> 跨篇累积。每处失分只归一类，六类标签固定：内容要点缺失 / 语言准确性 / 词汇与搭配 / 句式与衔接 / 篇章结构 / 字数与格式。

## 篇目登记

| 日期 | 篇目 | 类型 | 分数 | 档位 | 主要失分（3 条） |
|------|------|------|------|------|------------------|

## 标签统计

| 标签 | 累计次数 | 涉及篇数 | 典型例句 | 改法要点 |
|------|----------|----------|----------|----------|
| 内容要点缺失 | 0 | 0 | | |
| 语言准确性 | 0 | 0 | | |
| 词汇与搭配 | 0 | 0 | | |
| 句式与衔接 | 0 | 0 | | |
| 篇章结构 | 0 | 0 | | |
| 字数与格式 | 0 | 0 | | |

## 复发榜

按「累计次数 / 涉及篇数」降序，列前 3：

1. {标签} —— {次数} 次，{篇数} 篇
```

更新规则：

- 篇目登记每次批改追加一行
- 标签统计的「累计次数」累加本次错误清单中该标签的行数
- 「涉及篇数」：该标签在本篇出现 ≥1 次则 +1
- 「典型例句」只在新出现更典型例句时替换
- 计数必须等于各篇错误清单行数之和，提交前核对

## 二、高分表达库.md

```markdown
---
title: 高分表达库
type: 高分表达库
updated: {YYYY-MM-DD}
tags:
  - 作文
  - 表达
---

# 高分表达库

> 只收录从本人作文升级而来的句子，不收集外部范文。

## 图表描述

| 原句 | 升级句 | 适用场景 | 来源 |
|------|--------|----------|------|

## 原因分析

| 原句 | 升级句 | 适用场景 | 来源 |
|------|--------|----------|------|

## 结论与建议

| 原句 | 升级句 | 适用场景 | 来源 |
|------|--------|----------|------|

## 书信功能句

| 原句 | 升级句 | 适用场景 | 来源 |
|------|--------|----------|------|

## 通用衔接

| 原句 | 升级句 | 适用场景 | 来源 |
|------|--------|----------|------|
```

说明：

- 「来源」写篇目 wikilink，便于回查语境
- 同一原句再次出错时，不重复收录，改为在「适用场景」列补充提醒
- 已在考场可用的表达，标记 ✅；仍不熟练的标记 ⏳

## 三、作文索引.md

```markdown
---
title: 作文索引
type: 作文索引
updated: {YYYY-MM-DD}
tags:
  - 作文
  - 索引
---

# 作文索引

| 日期 | 类型 | 话题 | 分数/满分 | 档位 | 稿次 | 笔记 |
|------|------|------|-----------|------|------|------|

## 分数趋势

| 月份 | 篇数 | 平均分率 | 主要失分标签 |
|------|------|----------|--------------|
```

说明：

- 「分数/满分」列写成 `11/15` 形式，便于肉眼比较
- 「平均分率」= 分数 ÷ 满分，跨题型可比
- 索引只登记，不参与评分
