# 批改笔记模板（10 章固定结构）

> 所有章节标题、顺序固定。无内容时写「无」，不删章节。

---

## frontmatter

```yaml
---
title: "{YYYY-MM-DD} {类型} {话题} 批改"
type: 作文批改
essay_type: "大作文-柱状图"      # 小作文-书信 / 小作文-通知 / 大作文-柱状图 / 大作文-折线图 / 大作文-饼图 / 大作文-表格
topic: "{话题}"
exam_type: 英语二
prompt_source: "模拟题"          # 或 "2023 年真题"
score: 0                         # 实际得分
full_score: 15                   # 小作文 10，大作文 15
band: "第四档"                   # 第五档 ~ 第一档
word_count: 0
draft: 1                         # 1 = 一稿，2 = 二稿
tags:
  - 作文
  - 作文批改
  - 英语二
created: {YYYY-MM-DD}
updated: {YYYY-MM-DD}
sources: "素材/{同名}.jpg"
---
```

## 正文骨架

```markdown
# {类型} {话题} 批改

## 一、题目解析与任务点清单

题目原文：

> {题目英文原文}

任务点：

- [x] 任务点 1
- [ ] 任务点 2

格式要求（小作文）：

- [x] 称呼 / 结束语 / 署名 / 语域

## 二、原文转写

> 保留原始拼写与语法错误，未做任何纠正。

{逐段英文}

- 字数：{n} 词（要求约 {m} 词）
- 存疑处：{若有，逐条列出}

## 三、结构与段落分析

| 段落 | 功能 | 主题句 | 衔接手段 | 任务点落位 |
|------|------|--------|----------|------------|

整体判断：{结构是否服务于题目要求，是否套模板}

## 四、错误清单

| # | 原句 | 错因标签 | 问题说明 | 改法 |
|---|------|----------|----------|------|

标签计数：内容要点缺失 {n} · 语言准确性 {n} · 词汇与搭配 {n} · 句式与衔接 {n} · 篇章结构 {n} · 字数与格式 {n}

## 五、评分

| 评分维度 | 标准档位描述（引用） | 本篇表现 |
|----------|----------------------|----------|

字数与格式专项：{无 / 说明}

最终：**{档位} {区间} 分 → {得分} 分**

## 六、改稿 A｜最小改动版

{保留原句型与结构，只修错}

改动说明：{逐条对应错误清单编号}

## 七、改稿 B｜高分重写版

{重构衔接与表达，覆盖全部任务点}

改动理由：{逐处标注}

## 八、提分路径

从 {X} 分到 {Y} 分，只需改 3 件事：

1. {动作} —— 预计影响：{维度}
2. {动作}
3. {动作}

## 九、可迁移表达

| 原句 | 升级句 | 适用场景 |
|------|--------|----------|

## 十、复批建议

下次动笔前自查：

1. {自查项}
2. {自查项}
3. {自查项}
```

## 二稿模式追加块

插在「五、评分」之后：

```markdown
## 五之二、与一稿对比

| 维度 | 一稿 | 二稿 | 变化 |
|------|------|------|------|

- 已解决：{错因标签 + 条数}
- 仍存在：{错因标签 + 条数}
- 新出现：{错因标签 + 条数}
```

## 格式规范

- 表格前必须留空行，否则 Obsidian 渲染异常
- 不嵌套 callout；需要提示时用 `> [!tip]` 或 `> [!warning]` 单层
- 章节标题用 `## 一、` 至 `## 十、`，不使用 `####` 堆叠
- 英文原句与改稿保持原样，不用斜体替代引号
