# 单词辨析管理技能 (vocab-diff)

管理 `单词辨析.md` 笔记，帮助用户整理和维护易混淆单词。

## 触发场景

当用户表达以下意图时触发此技能：
- "XX和YY我总是记混"、"这几个词分不清"
- "帮我整理一下XX这类单词"
- "添加单词到辨析笔记"
- "查看单词辨析笔记"
- "搜索某个单词"
- 具体单词对："statue还是statute"、"affect还是effect"

## 核心功能

### 1. 添加新的易混淆单词对

当用户说"XX和YY记混了"或"帮我整理XX这类单词"时：

1. **读取现有笔记**：读取 `单词辨析.md`，获取当前最大编号
2. **分析单词**：理解用户提供的易混淆单词
3. **生成内容**：按照笔记现有格式生成新条目
4. **插入笔记**：将新条目添加到合适的分类下，或创建新分类

**条目格式**：
```markdown
### [编号]. [单词] [音标] [词性]. [中文释义]

**词根解析**：[词根分析]

**记忆方法**：
- [助记方法1]
- [助记方法2]

**常见搭配**：
- [搭配1]
- [搭配2]

**例句**：
> [英文例句，关键单词用 **粗体** 标记]

---
```

**分类规则**：
- 如果是现有词根系列（如STAT-、RESPECT-），添加到对应系列下
- 如果是新系列，创建新的 `## [词根]- 系列形近词` 章节
- 更新对应的对比总结表格

### 2. 搜索查看笔记

当用户说"查看单词辨析"或询问特定单词时：

1. 读取 `单词辨析.md`
2. 根据用户需求：
   - 查看全部：展示完整内容
   - 搜索特定单词：定位到相关条目并高亮显示
   - 查看特定系列：展示对应章节

### 3. 更新维护

当用户要求修改或更新时：

1. 读取现有内容
2. 按需修改（补充例句、更新记忆方法等）
3. 更新YAML frontmatter中的 `updated` 字段
4. 保持原有格式和结构

## 工作流程

### 添加新单词的标准流程

```
用户输入 → 读取笔记 → 分析单词 → 生成内容 → 插入笔记 → 报告结果
```

### 详细步骤

#### 步骤1：理解用户意图

用户可能说：
- "statue和statute我老是记混"
- "帮我整理一下respect系列的词"
- "affect和effect有什么区别"

提取出易混淆的单词列表。

#### 步骤2：读取现有笔记

读取 `单词辨析.md`，获取：
- 当前最大编号（用于新条目编号）
- 现有分类结构（决定添加到哪个系列）
- 对比总结表格（需要更新）

#### 步骤3：生成单词条目

为每个易混淆单词生成完整的辨析内容，包括：
- 词根解析
- 记忆方法（助记技巧）
- 常见搭配
- 例句

#### 步骤4：确定插入位置

- 如果是已有系列的单词（如STAT-），插入到该系列下
- 如果是新系列，创建新的章节标题
- 更新末尾的对比总结表格

#### 步骤5：写入文件

使用 Edit 工具精确插入新内容，保持格式一致。

#### 步骤6：报告结果

告诉用户：
- 添加了哪些单词
- 插入位置
- 更新后的编号

## 笔记结构规范

### YAML Frontmatter
```yaml
---
title: 考研英语常见易混淆单词辨析
type: 学习资料
topic: 词汇辨析
tags:
  - 词汇
  - 辨析
  - 易混淆
difficulty: 中等
created: YYYY-MM-DD
updated: YYYY-MM-DD  # 每次修改时更新
---
```

### 章节结构
```markdown
## [词根]- 系列形近词

### [编号]. [单词1] / [单词2] 对比

[单词1 详情]
---
[单词2 详情]
---

## [词根]- 系列对比总结

| 单词 | 发音 | 词性 | 含义 | 核心区别 |
|------|------|------|------|----------|
| ... | ... | ... | ... | ... |

---
```

### 单词条目格式
```markdown
### [编号]. [单词] /[音标]/ [词性]. [中文释义]

**词根解析**：[词源和词根分析]

**记忆方法**：
- [方法1：词根联想]
- [方法2：发音联想]

**常见搭配**：
- [搭配1]
- [搭配2]

**例句**：
> [例句，关键单词用 **粗体**]

---
```

## 约束

- 保持笔记格式的一致性
- 新增条目必须包含：词根解析、记忆方法、常见搭配、例句
- 更新时只修改必要部分，保持原有内容
- 每次修改都要更新 `updated` 字段

## 相关技能

- `extract-vocabulary` — 从文章中提取生词
- `translate` — 翻译文章时可能遇到的词汇
