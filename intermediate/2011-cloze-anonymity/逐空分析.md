## 重点错题深挖

### 第 2 空：while vs though（逻辑关系）

**原句**

Can privacy be preserved ___ bringing safety and security to a world that seems increasingly lawless?

**这题给了什么**

- `Can … ?` 是一个修辞问句，问的是"**两件事能否兼得**"。
- `bringing safety and security` 是 -ing 短语，逻辑主语与主句同指，说明它是**伴随动作**，不是已发生的事实。
- 下一段紧接着 `Last month, … offered … a proposal`——说明"带来安全"这件事**当时还没实现**，只是提案。

**为什么 though 不行**

- though 表让步时，默认"让步内容为真/已知"：`Though it brought safety, privacy could still be preserved` 才通。放进本句就变成"尽管已经带来安全"，与"提案尚未落地"的时间线打架。
- 而且 though 引导的从句通常要完整主谓，直接接 -ing 短语要额外解释，不自然。

**为什么 while 赢**

- while 有两个常用义：① 在……的同时（时间/伴随）；② 然而、尽管（对比）。本句取 ①，正好对应"同时兼得"的问句逻辑，且 `while + doing` 是标准省略结构。

> [!warning] 可迁移规则
> **连词题先问"这一句的语气是问、是断言、还是让步"。**
> - 问句 + `Can` → 优先"同时/条件"类连词（while / if / unless）。
> - 让一步词（though / although / even if）只有在**承认既成事实**时才用。
> 本篇你选了 though，是把"提议中的事"当成"已发生的事"，方向错了。

### 第 5 空：equivalent vs information（词义辨析）

**原句**

a "voluntary trusted identity" system that would be the high-tech ___ of a physical key, a fingerprint and a photo ID card, all rolled into one.

**这题给了什么**

- 破折号后的 `a "voluntary trusted identity" system` 是对空处所在名词短语的**同位解释**。
- `the high-tech ___ of A, B and C` 这个框架本身要求：空处名词能与 `of + 三个实体` 构成"**A 是 B、C、D 的……**"关系。
- 三个实体全是**实体凭证**（钥匙、指纹、带照片的身份证），"系统把三者合一"→ 系统是它们的"替代物/等值物"。

**为什么 information 不行**

- information 与 key / fingerprint / ID card 不构成"等值替代"关系——你无法说"这个系统是钥匙的信息"。
- information 是不可数名词，与 `all rolled into one`（三者合一）的"多个实体合成一个"也不呼应。
- 此外 interference（干扰）、entertainment（娱乐）与全文主题完全无关，是纯干扰。

**为什么 equivalent 赢**

- `the equivalent of X` = X 的等价物、对应物，正是"实体三件套"在数字世界的高科技对应版本。
- 与后文 `digital credential`、`smart identity card` 形成同一语义场。

> [!warning] 可迁移规则
> **`the ___ of + 一组实体` 的框架，必须选"关系名词"（equivalent / counterpart / substitute / version），不能选"内容名词"（information / knowledge / idea）。**
> 判断口诀：of 后面是**具体东西**，空处多半是"对应物/替代品"；of 后面是**抽象概念**，空处才可能是"内容/含义"。

### 第 10 空：issued vs distributed（固定搭配）

**原句**

The approach contrasts with one that would require an Internet driver's license ___ by the government.

**这题给了什么**

- `a license ___ by the government`：`by + 施动者` 是**被动**的强信号，空处应为过去分词。
- 名词是 license（执照）——证照类名词有自己的固定动词。

**为什么 distributed 不行**

- distribute 的对象是**可分发扩散的物品**：leaflets, food, vaccines, software。语义重心是"散发到多处"。
- 政府"分发执照"这种说法不成立——执照不是批量散发品，而是逐一审核后签发。

**为什么 issued 赢**

- `issue a license / a passport / a visa / a certificate` 是固定动宾，法律文书的标准搭配，义为"签发、发放（证照）"。
- 干扰项里 released 也是"发放"的常见译法，但它配消息（release a statement）、影片（release a film）、人员（release a prisoner），同样不配 license。

> [!warning] 可迁移规则
> **证照类名词，先想它的专属动词，别从中文"发"倒推。**
> - issue a license / visa / passport / certificate（签发）
> - grant a permit / a right（授予）
> - renew / revoke a license（续期 / 吊销）
> 中文一个"发"字，覆盖了 issue（签发证照）、distribute（分发物资）、release（发布消息）、deliver（投递物品）四种英文，这正是这类题的设陷点。

### 第 17 空：eventually vs incidentally（逻辑关系）

**原句**

It seems clear that such a scheme is an initiative push toward what would ___ be a compulsory Internet "driver's license" mentality.

**这题给了什么**

- `an initiative push toward` ——"朝……推进的第一步"，方向指向**未来**。
- `what would ___ be` ——would + be 表**推测的未来状态**，空处要补一个"时间推进"副词。
- 本段整体语义：现在是"自愿"，但这是在把大家一步步推向"强制"。

**为什么 incidentally 不行**

- incidentally = 顺便提一句、偶然地，表**话语层面**的补充说明或事件发生的偶然性，完全不表时间推进。
- 放进本句变成"顺便成为强制的思维"，逻辑断裂。

**为什么 eventually 赢**

- eventually = 最终、终于，与 `push toward`（推向）和 `would be`（将来会成为）构成完整的时间链：现在主动推 → 将来最终变成强制。
- 同段的 `frequently / occasionally` 是频率副词，与"终点状态"无关，属同一类干扰。

> [!warning] 可迁移规则
> **副词题先看句子是"时间线"还是"频率"。**
> - 出现 `push toward / would / in the end / at last / over time` → 时间终点类（eventually / ultimately）。
> - 出现 `often / usually / sometimes` 的语境 → 频率类（frequently / occasionally）。
> 本篇你选了 incidentally，是把它当"顺便"读了，但句子的骨架是"推向未来"。

### 第 19 空：vulnerable vs manageable（词义辨析）

**原句**

computer security experts, who worry that the "voluntary ecosystem" … would still leave much of the Internet ___.

**这题给了什么**

- `who worry that` ——**担忧**，语气已定为负面。
- `leave + 宾语 + 形容词`（宾补）：空处必须是描述 Internet 状态的形容词。
- 下一句 `They argue that all Internet users should be forced to register` ——专家主张"强制注册"，说明他们认为现状**不安全**。

**为什么 manageable 不行**

- manageable = 可管理的、可应付的，是**褒义/中性偏正面**的评价。如果网络"可管理"，专家就没有担忧的理由。
- 这是本篇最典型的"**语气反向**"错误：单看语法完全成立（leave + 宾语 + 形容词），但情绪方向与 who worry 相反。

**为什么 vulnerable 赢**

- vulnerable = 易受攻击的、脆弱的，正是安全专家对"自愿制"的核心批评：自愿 = 可以不参加 = 剩下的人仍然暴露。
- 与第 9 段整体论证链一致：自愿生态 → 仍有一大片不设防 → 所以应当强制。

> [!warning] 可迁移规则
> **看到 who worry / critics / concern / skeptics，先把空处的感情色彩锁定为负面，再去挑词。**
> 本篇 18、19 两空同属一条证据链（greeted with skepticism → leave … vulnerable），语气一致。做 19 空时若回看 18 空的 skepticism，几乎不可能选 manageable。

### 第 18 空：skepticism vs tolerance（框架对、内容错，高价值陷阱）

**原句**

The plan has also been greeted with ___ by some computer security experts.

**这题给了什么**

- `be greeted with ___` 框架只决定"遭到某种反应"，**不决定是哪种反应**——这是本篇最容易误判为"搭配题"的地方。
- 真正定答案的是后面的定语从句：`who worry that …` → 担忧 = 质疑。
- 段首 `also` 提示：与第 8 段 `has divided privacy rights activists` 并列，同为负面反应。

**为什么 tolerance 不行**

- tolerance = 容忍、宽容，语气是"接受但不热情"，与 `worry` 不搭。
- indifference = 漠不关心——漠不关心的人不会写 `who worry that` 的长句去批评。
- enthusiasm = 热情，方向完全相反。

> [!tip] 可迁移规则
> **`be greeted with / be met with / respond with` 这类"反应框架"只锁词性，不锁褒贬。**
> 褒贬必须从句子里另找证据：who worry / critics argue / Some applaud … others are concerned。

### 第 20 空：forced vs allowed（语气方向，高价值陷阱）

**原句**

They argue that all Internet users should be ___ to register and identify themselves, in the same way that drivers must be licensed to drive on public roads.

**这题给了什么**

- `in the same way that drivers must be licensed` ——类比句，`must` 表强制。
- `They argue that … should be` ——专家主张，语气是"应当（必须）"。
- 全文对立轴：voluntary（自愿）↔ compulsory（强制）。专家要的正是后者。

**为什么 allowed 不行**

- be allowed to do = 被允许做，语义是"可以但不必须"，与 must be licensed 的强制语义正好相反。
- invited = 受邀，更弱；appointed = 被任命，主语必须是被任命的职位人选。

**为什么 forced 赢**

- be forced to do = 被迫做，与 `must` 同强度，也回扣第 8 段 `compulsory`、第 4 段 `require`。

> [!tip] 可迁移规则
> **类比句（in the same way that / just as / like）是语气标尺。**
> 类比对象里出现 must / have to / be required to，空处就必须是同强度的强制词；出现 can / may，才是允许类。

## 结构性长难句（供 P6 第七章使用）

本篇失分**没有一空是纯语法结构判断错误**（语法标签 0），以下两句只是结构上容易看错，列为"结构提醒"而非失分点：

1. `a "voluntary trusted identity" system that would be the high-tech equivalent of a physical key, a fingerprint and a photo ID card, all rolled into one.` —— 定语从句 + `all + 过去分词` 独立结构，注意 `all` 指的是前面三项。
2. `the identities of the infrastructure on which the transaction runs` —— `介词 + which` 定语从句，介词由 `run on` 决定。
