# 2011 完形填空 固定搭配与词组

> 本篇是**政策争议类**文章，搭配密度集中在中段（第 3—4 段的技术描述）和尾段（第 8—9 段的争议表达）。📌 为本篇直接考点，共 14 处。

## 一、主题词：网络身份与隐私

| 搭配 | 释义 | 原文 |
|---|---|---|
| anonymity | 匿名性 | The Internet affords **anonymity** to its users |
| a blessing to sb. | 对某人是幸事 | **a blessing to** privacy and freedom of speech |
| freedom of speech | 言论自由 | privacy and **freedom of speech** |
| cyber-crime | 网络犯罪 | the explosion of **cyber-crime** |
| cyber-czar | 网络总管 | Howard Schmidt, the nation's **cyber-czar** |
| voluntary trusted identity | 自愿可信身份 | a "**voluntary trusted identity**" system |
| digital credential | 数字凭证 | a **digital credential** linked to a specific computer |
| authenticate users | 验证用户身份 | would **authenticate users** at a range of online services |
| single sign-on | 单点登录 | these "**single sign-on**" systems |
| walled garden | 围墙花园（受控封闭生态） | create a "**walled garden**" in cyberspace |
| voluntary ecosystem | 自愿生态 | described it as a "**voluntary ecosystem**" |
| privacy rights activist | 隐私权活动人士 | has divided **privacy rights activists** |
| computer security expert | 计算机安全专家 | greeted with skepticism by some **computer security experts** |

> [!note] 语义场提示
> 本篇有两组对立词，贯穿全篇：
> - **匿名 ↔ 身份**：anonymity / privacy ↔ identify / authenticate / register / license
> - **自愿 ↔ 强制**：voluntary ↔ compulsory / forced / require / must
> 空周围只要出现这两组的任一侧，答案方向基本就定了。

## 二、高频固定搭配（📌 本篇考点）

| 搭配 | 释义 | 原文 / 考点 |
|---|---|---|
| 📌 **sweep across** | 席卷、迅速蔓延至 | cyber-crime that has **swept across** the Web（空 1） |
| 📌 **all rolled into one** | 全部融为一体 | a key, a fingerprint and a photo ID card, **all rolled into one**（空 6） |
| 📌 **roll A into B** | 把 A 卷进 B → 合并 | rolled **into** one（空 6 的介词依据） |
| 📌 **be linked to** | 与……相连、绑定 | a digital credential **linked to** a specific computer（空 7） |
| 📌 **create a federation of** | 建立一个……联盟 | to **create a federation of** private online identity systems（空 8） |
| 📌 **select which … to join** | 选择加入哪一个 | User could **select which system to join**（空 9） |
| 📌 **issue a license** | 签发执照 | a driver's license **issued by** the government（空 10） |
| 📌 **log in** | 登录 | make it possible for users to **log in** just once（空 11） |
| 📌 **in effect** | 实际上、事实上 | **In effect**, the approach would create …（空 12） |
| 📌 **with confidence** | 满怀信心地 | complete online transactions **with confidence**（空 14） |
| 📌 **run on sth.** | 在……上运行 | the infrastructure **on which** the transaction **runs**（空 15） |
| 📌 **be greeted with** | 遭到（某种反应） | has also been **greeted with skepticism**（空 18） |
| 📌 **leave sb./sth. + adj.** | 使……处于某状态 | would still **leave** much of the Internet **vulnerable**（空 19） |
| 📌 **be forced to do** | 被迫做 | should be **forced to** register（空 20） |
| **contrast with** | 与……形成对照 | The approach **contrasts with** one that would require … |
| **a push toward** | 朝……推进的一步 | an initiative **push toward** what would eventually be … |
| **divide sb.** | 使某人分裂、产生分歧 | has **divided** privacy rights activists |
| **in the same way that** | 正如……一样 | **in the same way that** drivers must be licensed |
| **a sense of community** | 社区感 | establish **a sense of a trusted community** |
| **at a range of** | 在一系列……上 | authenticate users **at a range of** online services |
| **a step toward** | 迈向……的一步 | an initiative push **toward** |

> [!warning] 三个最容易看走眼的框架
> 1. `all rolled ___ one` → 只能填 **into**。判断依据不是"卷"这个动作，而是 `roll A into B` 的固定用法。
> 2. `a license ___ by the government` → 只能填 **issued**。`issue a license / a passport / a visa` 是固定动宾；distribute 指分发物资，release 指发布消息。
> 3. `the infrastructure ___ which the transaction runs` → 只能填 **on**。把从句还原成 `the transaction runs on the infrastructure`，介词自然浮出。

## 三、动词搭配与干扰项辨析

| 动词 | 正确搭配 | 本篇干扰项与错因 |
|---|---|---|
| sweep | sweep across / sweep through（席卷） | skipped 跳过（动作不连续）、walked 走、ridden 骑——都不能描述犯罪"蔓延覆盖全域" |
| link | be linked to（绑定、关联） | directed to 指向（宾语应为注意力/方向）、chained to 用链条拴住（过强）、compared to 被比作 |
| issue | issue a license / passport / visa（签发） | released 发布消息、distributed 分发物资、delivered 投递物品 |
| create | create a federation / a system（创建体系） | dismiss 驳回、discover 发现（已有之物）、improve 改进（需先存在） |
| select | select which … to join（挑选） | recall 回忆起、suggest 建议、realize 意识到——都是"心里活动"，不能带 which … to join |
| log in | log in once（登录一次） | carry on 继续、linger on 徘徊不去、set in（不良天气/情绪）开始 |
| divide | divide sb.（使分裂） | disappointed 使失望（对象是期望，不是人群之间的关系）、protected 保护、united 使团结（与后文矛盾） |
| greet | be greeted with skepticism（遭到质疑） | 该框架只决定后面的名词，不决定名词本身，属"框架对、内容错"的典型 |
| leave | leave sth. + 形容词（使保持某状态） | 宾补位置必须形容词；manageable / defendable / invisible 都合法但语义不合语气 |
| force | force sb. to do（强制） | invited 邀请（语气反向）、appointed 任命（主语须是人）、allowed 允许（可做可不做） |

> [!tip] 一条通用判断
> 动词题先看**宾语**再选动词。`___ a federation` 的宾语是"组织体"，只能 create/establish/form；`___ a license` 的宾语是"证照"，只能 issue/grant；`___ which system to join` 的宾语是"选择项"，只能 select/choose/decide。

## 四、速记卡片：逐段信号词 → 答案

| 段 | 信号词 / 结构 | 管住的空 | 答案与理由 |
|---|---|---|---|
| 1 | `But` + `across the Web` | 1 | swept（犯罪"席卷"全网，与 across 呼应） |
| 2 | `Can … be preserved ___ bringing` + `increasingly ___` | 2、3 | while（同时）、lawless（世界"无法无天"才需要安全） |
| 3 | `offered … a ___` / `high-tech ___ of A, B and C` / `all rolled ___ one` / `credential ___ to a computer` | 4、5、6、7 | proposal / equivalent / into / linked |
| 4 | `The idea is to ___ a federation` / `could ___ which system to join` / `license ___ by the government` | 8、9、10 | create / select / issued |
| 5 | `single sign-on` / `___ just once but use many services` | 11 | log in（与 sign-on 同义场） |
| 6 | `___, the approach would create` / `a sense of a ___ community` | 12、13 | In effect（承接上文、作结论）/ trusted（全文核心词） |
| 7 | `transactions with ___` / `infrastructure ___ which … runs` | 14、15 | confidence（信任才敢交易）/ on（run on） |
| 8 | `Still` / `has ___ activists` / `would ___ be compulsory` | 16、17 | divided（后文 Some… others… 是直接证据）/ eventually（push toward 指向未来结果） |
| 9 | `also` / `greeted with ___` / `leave much of the Internet ___` / `should be ___ to register` | 18、19、20 | skepticism（who worry that 定调负面）/ vulnerable（专家担忧的状态）/ forced（与 must be licensed 同向） |

> [!tip] 完形速记法
> 把这张表当"答题地图"用：先读段首与信号词，判断该段管住哪几个空，再看选项。本篇 20 个空，**有 14 个的答案方向由信号词单独决定**（But / Still / also / contrasts with / push toward / in the same way that），不需要逐词翻译整句。
