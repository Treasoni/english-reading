# 2011 完形填空 语法整理

> 只收**影响选空判断**的语法点。本篇真正被语法决定答案的空是 2（while）、6（into）、7（linked）、10（issued）、15（on）、19（vulnerable 宾补）、20（forced 被动）。

### 第 2 空：while 引导的伴随/让步状语

**原文**

Can privacy be preserved **while** bringing safety and security to a world that seems increasingly lawless?

**结构**

`while + 现在分词短语`：while 后主语与主句主语同指（privacy / we），故省略主语，只留 -ing 形式，表"在……的同时"。

| 成分 | 内容 |
|---|---|
| 主句 | Can privacy be preserved |
| 连词 | while（同时、尽管） |
| 状语 | bringing safety and security to a world … |
| 定语从句 | that seems increasingly lawless（修饰 world） |

> [!warning] 为什么不是 for / within / though
> - `for + doing` 表目的（"为了带来安全"）——但本句问的是"能否同时兼得"，不是目的，且 `preserved for bringing` 语义打架。
> - `within + doing` 表范围，`preserved within bringing` 不成立。
> - `though` 引导让步从句需接完整句子或形容词，不能直接接 -ing 短语表"同时"，且 though 的"尽管"会把句子变成"尽管带来安全，隐私还能保全吗"，语气是承认已带来安全，与下一段"提案尚未落地"矛盾。

### 第 6 空：all rolled into one

**原文**

a "voluntary trusted identity" system that would be the high-tech equivalent of a physical key, a fingerprint and a photo ID card, **all rolled into one**.

**结构**

`all + 过去分词短语` 构成独立结构（独立主格），逻辑主语是前面的三项（key / fingerprint / ID card），rolled 与它们是**被动**关系。

| 结构 | 作用 |
|---|---|
| `all rolled into one` | 独立结构，补充说明三项"被卷成一体" |
| `roll A into B` | 把 A 卷进 B → 融为、合并为 |

> [!warning] 为什么不是 by / from / over
> 判断 rolled 后面接什么介词，要看动词本身的搭配：`roll sth. into sth.` 才是"合并成一个"。`rolled by one`（被一个……卷）、`rolled from one`（从一个卷起）、`rolled over one`（从一个上方滚过）都不表"融为一体"。
> 这一空的关键不在语法术语，而在**动词搭配**：见 [[固定搭配与词组笔记]] 的 `roll into one`。

### 第 7 空：过去分词短语作后置定语

**原文**

a digital credential **linked** to a specific computer

**结构**

`credential` 与 `link` 是被动关系 → 用过去分词 `linked` 作后置定语，等于 `which is linked to a specific computer`。

| 选项 | 判定 |
|---|---|
| linked | ✅ `be linked to` 与……相连/绑定，被动关系成立 |
| directed | ❌ direct 的宾语通常是"注意力/方向"，`directed to` 表"指向"，credential 不"指向"电脑 |
| chained | ❌ 语义过强（用链条拴住），且 `chained to` 含贬义束缚 |
| compared | ❌ `be compared to` 表"被比作"，与"绑定到某台电脑"无关 |

### 第 10 空：过去分词短语作后置定语（被动来源）

**原文**

an Internet driver's license **issued** by the government

**结构**

`license` 是被政府"签发"的对象 → 过去分词 `issued` 后置，等于 `which is issued by the government`。`by + 施动者` 是判定被动的强信号。

| 选项 | 判定 |
|---|---|
| released | ❌ release 指发布消息、发行影片、释放人员；license 不说 release |
| issued | ✅ issue a license 是固定说法（签发证照） |
| distributed | ❌ distribute 指分发、配销（物资），强调"散发到多处" |
| delivered | ❌ deliver 指投递、交付（物品、演讲） |

> [!tip] 判定顺序
> 看到 `___ by the government` 先问两件事：① 空处是不是被动分词；② 哪个动词能与前面的名词构成固定动宾（issue a license）。两步都过才选。

### 第 15 空：介词 + which 定语从句

**原文**

the identities of the infrastructure **on** which the transaction runs

**结构**

`介词 + which` 引导定语从句，先行词是 `infrastructure`。介词由从句中的动词搭配决定：`run on sth.` = 在……上运行。

| 成分 | 内容 |
|---|---|
| 先行词 | the infrastructure |
| 介词 | on（来自 run on） |
| 从句 | which the transaction runs |
| 还原 | the transaction runs **on** the infrastructure |

> [!warning] 为什么不是 after / beyond / across
> `run after` 追赶、`run beyond` 超出、`run across` 偶遇——都不能表达"交易在基础设施上运行"。介词 + which 题的唯一解法是**把从句还原成陈述句**，看动词要哪个介词。

### 第 19 空：leave + 宾语 + 形容词（宾补）

**原文**

would still leave much of the Internet **vulnerable**

**结构**

`leave + 宾语 + 形容词` 表示"使……保持某种状态"，形容词作宾语补足语。

| 选项 | 判定 |
|---|---|
| manageable | ❌ 可管理的（褒义），与专家"担忧"的语气相反 |
| defendable | ❌ 可辩护的/可防守的，语义指向"论点/阵地" |
| vulnerable | ✅ 易受攻击的，正是安全专家所担忧的状态 |
| invisible | ❌ 看不见的，与"安全"无关 |

> [!tip] 宾补位置先定词性
> `leave much of the Internet ___` 后面没有名词、没有 to do，空处必须是**形容词**且描述宾语状态。四个选项都是形容词，所以这一空靠的是**语义与语气**（who worry that … 已定调为负面），不是靠词性。

### 第 20 空：should be forced to do（被动 + 不定式）

**原文**

all Internet users should be **forced** to register and identify themselves

**结构**

`force sb. to do sth.` 的被动式 `sb. be forced to do sth.`，主语是"被强制"的一方。

| 选项 | 判定 |
|---|---|
| invited | ❌ 结构成立（be invited to do），但语气是"受邀"，与专家主张的"应当强制"矛盾 |
| appointed | ❌ appoint sb. to do 表"任命某人做某事"，主语必须是人被任命，users 不成立 |
| allowed | ❌ be allowed to do 表"被允许"，方向相反（允许 = 可做可不做） |
| forced | ✅ be forced to do 被强制做，与 `in the same way that drivers must be licensed` 的强制语义一致 |

### 第 3 空：that 定语从句修饰 world

**原文**

a world **that** seems increasingly lawless

**结构**

`that` 引导定语从句修饰 world，seems 后接形容词作表语，increasingly 修饰形容词表程度加深。

> [!note] 提示
> 这一空不是语法题而是词义题（lawless 无法无天），列在此处只为说明句子结构：`seems increasingly ___` 后必须是一个能修饰"世界"的形容词，且要与 cyber-crime 的语境同向。

### 第 8、9、16 空：不定式表语与并列谓语

**原文**

The idea is to **create** a federation … / User could **select** which system to join / the plan has **divided** privacy rights activists

**结构**

| 空 | 结构 | 说明 |
|---|---|---|
| 8 | `be to do` 作表语 | The idea is to create …，说明"构想的内容" |
| 9 | `could + 动词原形` + 宾语从句 | select which system to join，`疑问词 + to do` 作宾语 |
| 16 | `have + 过去分词` 完成体 | has divided …，表"已经造成（分裂）的结果" |

> [!tip] 时态提示
> 第 16 空 `has divided` 是现在完成时，强调结果留存到现在；能与之搭配的只有表"造成分歧"的词。`has protected / has united` 与后文 `Some applaud … others are concerned` 直接矛盾。
