# 2013 完形填空 固定搭配与词组笔记（无现金社会）

## 二、高频固定搭配

| 搭配 | 释义 | 原文 | 考点 |
|---|---|---|---|
| 📌 around the corner | 即将到来、就在眼前 | a true cashless society is probably not around the corner | 反衬"并未到来"，支撑第 1 空转折 |
| 📌 be around | 存在、流传、还在 | predictions have been around for two decades | **第 2 空答案** |
| 📌 come to fruition | 成为现实、结出果实 | have not yet come to fruition | 与 be around 形成"存在但未实现"的对照 |
| 📌 the very + 名词 | 正是、恰恰（强调） | revolutionize the very concept of money itself | 强调"概念本身"，第 3 空取 concept |
| 📌 only to do | 结果却（出乎意料） | only to reverse itself several years later | **第 4 空结构** |
| 📌 be slow in doing | 做某事迟缓 | so slow in coming | **第 5 空搭配** |
| 📌 work against | 不利于、阻碍 | several factors work against the disappearance | **第 6 空答案** |
| 📌 it is + adj. + to do | 做某事是……的（形式主语） | it is very expensive to set up … | **第 7 空结构** |
| 📌 make A B | 使 A 成为 B | make electronic money the dominant form of payment | 第 8 空宾补位置 |
| 📌 have the advantage that … | 优势在于…… | paper checks have the advantage that they provide receipts | **第 9 空同位语从句** |
| 📌 be unwilling to do | 不愿做某事 | many consumers are unwilling to give up | **第 10 空答案** |
| 📌 It takes + 时间 + before … | 过……（时间）才…… | it takes several days before a check is cashed | **第 11 空结构** |
| 📌 withdraw funds from an account | 从账户中划出资金 | funds are withdrawn from the issuer's account | **第 12 空答案** |
| 📌 earn interest on | 就……赚取利息 | earn interest on the funds in the meantime | 解释消费者为何舍不得浮存期 |
| 📌 in the meantime | 在此期间 | in the meantime | 时间状语，锁定"浮存期内" |
| 📌 raise concerns | 引发担忧 | may raise security and privacy concerns | **第 14 空答案** |
| 📌 alter information | 篡改信息 | alter information stored there | 与 store 构成"存储—篡改"链 |
| 📌 not an uncommon occurrence | 并非罕见之事 | this is not an uncommon occurrence | **第 16 空双重否定** |
| 📌 steal from sb.'s account | 从某人账户盗取 | steal from someone else's accounts | **第 17 空答案** |
| 📌 the prevention of fraud | 防范欺诈 | The prevention of this type of fraud | **第 18 空答案** |
| 📌 no easy task | 绝非易事 | is no easy task | 提示空处须是"一项任务/工作"类名词 |
| 📌 cope with | 应对、处理（问题） | developing to cope with security issues | **第 19 空答案** |
| 📌 leave a trail | 留下痕迹 | leaves an electronic trail | **第 20 空答案** |
| 📌 violate privacy | 侵犯隐私 | thereby violating our privacy | 全篇收束搭配 |
| a large amount of | 大量的（+ 不可数） | a large amount of personal data | 与 data 的不可数用法一致 |
| be based on | 以……为基础 | a payments system based on paper | 第 2 段开篇对比框架 |
| move to | 转向、迈向 | move quickly to the cashless society | 全文起点动作 |
| set up | 建立、搭建 | to set up the computer, card reader … | 成本高的对象 |
| be able to do | 能够做 | might be able to access bank accounts | 与 steal 共用 |
| access a database | 进入/访问数据库 | access a computer database | access 作动词，及物 |
| a further concern is that … | 另一个担忧是…… | A further concern is that … | 推进第四点，收束隐私维度 |

## 三、动词搭配与干扰项辨析

| 动词组 | 正确项用法 | 干扰项为何不适合本篇 |
|---|---|---|
| reverse / reward / resist / resume | `reverse itself` = 自我推翻、反转（刊物推翻自己的预测） | reward 奖励（主语须是人或机构给他人）；resist 抵制（须接被抵制对象）；resume 恢复（须是中断过的事） |
| provide / collect / copy / print | `provide receipts` = 提供收据（支票的功能） | collect 收取（方向相反：是消费者拿收据）；copy 复印、print 打印（都不是支票的法定功能） |
| give up / take over / bring back / pass down | `give up receipts` = 放弃收据 | take over 接管（对象须是职责、公司）；bring back 带回（方向相反）；pass down 传下（世代/上下级） |
| withdrawn / kept / borrowed / released | `funds are withdrawn from the account` = 资金被划出 | kept 留存（方向相反）；borrowed 借入（主语是借入方）；released 释放（用于人质、气体、新闻稿） |
| raise / hide / express / ease | `raise concerns` = 引发担忧 | hide 隐藏（与"引发"相反）；express 表达（主语须是有观点者）；ease 缓解（方向相反） |
| steal / choose / benefit / return | `steal from sb.'s account` = 从账户盗取 | choose 选择（须有选择对象）；benefit 受益（benefit from 才成立，且语气相反）；return 归还（方向相反） |
| cope with / fight against / adapt to / call for | `cope with issues` = 应对问题 | fight against 多接 enemy / crime / poverty 这类"对手"；adapt to 适应（不解决问题）；call for 要求（主语须是倡议者） |

> [!warning] 三个最容易被"语感"带偏的搭配
> 1. `have been ___ for two decades but have not yet come to fruition` → **around**。but 要求前半句是"存在、流传"，over（结束）会与后半句打架。
> 2. `several factors work ___ the disappearance` → **against**。work against = 阻碍；work for 才是"有利于"，with / on 都不构成"阻力"义。
> 3. `developing to ___ security issues` → **cope with**。issues 只能被"处理/应对"，不能被"对抗"；fight against 的宾语是敌人或社会顽疾。
