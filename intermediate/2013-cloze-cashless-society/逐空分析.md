# 2013 完形填空 逐空分析（无现金社会）

> 读取方式：先看「判断依据 / 线索词」，再核对「干扰项为何错」，最后一列是本空的错因归属。20 空全答，无漏答。

## 一、逐空判定表

## 三、重点错题深挖

### 第 1 空：However vs Moreover —— 转折与递进的分水岭（逻辑关系）

- 文章给你什么：前句 `you might think that we would move quickly to the cashless society`（乐观预期），本句 `a true cashless society is probably not around the corner`（否定）。两句一正一反，中间只能填转折。
- 你的选择为何失败：Moreover 是**递进**，它要求后句与前句同向加分（"而且……"）。但后句说的是"并未到来"，与"会很快实现"直接冲突；Moreover 一旦填入，整段就变成"我们会很快进入无现金社会，而且这个社会还没到来"，自相矛盾。
- 正确项为何胜出：However 表转折，且是**连接副词**，与后面的逗号构成插入式位置。全篇的结构就是"让步—转折—设问—解答"，这一空是总开关。
- 可迁移规则：**看到"你也许会认为……"这种让步式开头，空处九成是转折词。** 先判断后句与前句同向还是反向：同向选 Moreover / Furthermore，反向选 However / Nevertheless，因果选 Therefore，条件假设选 Otherwise。

### 第 2 空：around 的"存在"义（固定搭配）

- 文章给你什么：`Indeed, predictions have been ___ for two decades but have not yet come to fruition.` —— 前半句是 but 之前的让步，后半句才是重点：尚未实现。
- 你的选择为何失败：over 让句子变成 "predictions have been over for two decades"（预言已经结束二十年），与"但尚未实现"直接打架：如果早结束了，就不存在"尚未实现"的问题。
- 正确项为何胜出：`be around` = 存在、流传、还在（be here / be there / be around 同属"存在"类表语）。预言"已经存在二十年，但还没兑现"正好是预言类话题的标准说法。
- 可迁移规则：**be + 方位副词作表语时，先查"是否习语"。** around = 存在/在附近，over = 结束，off = 离开/关闭，back = 回来。四个词靠的不是方位想象，而是固定含义。

### 第 11 空：It takes … before … —— 时间先后（逻辑关系）

- 文章给你什么：`it takes several days ___ a check is cashed and funds are withdrawn from the issuer's account` —— 整句在讲"浮存期"：支票兑现要等几天。
- 你的选择为何失败：when 表"当……时"，会读成"支票兑现时需要好几天"，语义变成"兑现这个动作本身耗时"，而原文要表达的是"从开票到兑现，中间隔好几天"。
- 正确项为何胜出：`It takes + 时间段 + before + 从句` = "过……才……"，是英语里极常见的句型，before 从句用一般现在时表将来。这里 before 既表时间先后，也呼应下句 `in the meantime`（在此期间）。
- 可迁移规则：**看到 It takes / It took + 时间，先想 before。** 如果后面接的是"事情发生"，基本就是 before；接 since 需完成时，接 when 会变成"耗时"而非"等待"。同族句型还有 `It will be + 时间 + before …`。

### 第 12 空：withdraw funds from an account（固定搭配）

- 文章给你什么：`funds are ___ from the issuer's account` —— 主语 funds（资金），方向 from the account（从账户出去），且是被动语态。
- 你的选择为何失败：released 的核心义是"放开、释放"（release a prisoner / gas / a report），与"资金从账户流出"不搭；银行语境里"划出资金"只能用 withdraw。
- 正确项为何胜出：`withdraw money / funds from an account` 是金融领域的固定搭配；`are withdrawn` 与前面的 `a check is cashed` 并列在同一时间状语从句中，都是被动。
- 可迁移规则：**资金类动词按方向记：deposit / put in（存入）↔ withdraw / take out（取出）↔ transfer（转账）。** 干扰项若出现 release / keep / borrow，先检查"方向"和"语域"。

### 第 13 空：Because 的因果 vs Though 的让步（逻辑关系）

- 文章给你什么：`___ electronic payments are immediate, they eliminate the float for the consumer.` 前句（从句）讲"即时"，后句（主句）讲"取消浮存期"。即时正是浮存期消失的**原因**。
- 你的选择为何失败：Though 让步会得到"尽管电子支付是即时的，它们却取消了消费者的浮存期"——"尽管"要求前后有反差，但"即时"和"取消浮存期"恰恰是顺承关系，毫无反差可言。
- 正确项为何胜出：Because 引导原因状语从句，主句给结果，与第 2 段 Third 的整段论证（浮存期是纸质支票的隐性收益）完全咬合。
- 可迁移规则：**先判断两句是"顺承"还是"反差"。** 顺承用 because / since / as（因果）或 so（结果）；反差才用 though / although / while。填入让步连词后如果读不出"意想不到"，就是选错了。

### 第 16 空：not + uncommon 的双重否定（词义辨析）

- 文章给你什么：`We often hear media reports that an unauthorized hacker has been able to access a computer database` + `The fact that this is not an ___ occurrence` —— 前面反复说"常听到"，所以这件事是"常见"的。
- 你的选择为何失败：unsafe 是"不安全的"，它描述的是风险属性，不能修饰 occurrence（发生的事件）；而且 "not an unsafe occurrence" 会变成"不是不安全的事件"，与"黑客频发"毫无关系。
- 正确项为何胜出：`not an uncommon occurrence` = 并非罕见之事（双重否定表肯定），恰好承接前句"我们常听到报道"，并顺势推出"不诚实的人也可能这样做"。
- 可迁移规则：**空处前面有 not，先看选项是否含否定词缀。** not + un- / in- / dis- = 肯定；这类空往往不是考词汇量，而是考"有没有看见 not"。

### 第 18 空：prevention 的名词选择（词义辨析）

- 文章给你什么：`The ___ of this type of fraud is no easy task, and a new field of computer science is developing to cope with security issues.` —— 后半句"新领域发展以应对安全问题"直接说明这个名词是"防范"。
- 你的选择为何失败：consideration 是"考虑"，"考虑欺诈绝非易事"虽语法成立，但与"新领域专门发展来应对"不匹配——"考虑"不需要一整个学科；manipulation（操纵）与防诈方向相反。
- 正确项为何胜出：prevention 与 `no easy task` 搭配自然（防范是一项任务），并与后句 `cope with security issues` 同义复现。
- 可迁移规则：**名词空先问"这个名词能不能当一项 task / job 去做"。** consideration 是心理活动，prevention 是实际行动；凡后文出现"发展、投入、建立"类动作，答案多是行动类名词。

### 第 19 空：cope with vs fight against（固定搭配）

- 文章给你什么：`a new field of computer science is developing to ___ security issues` —— 宾语是 security **issues**（问题），不是敌人。
- 你的选择为何失败：fight against 的宾语通常是"对手"或"社会顽疾"：fight against crime / poverty / an enemy / discrimination。把 issues 塞进去，读成"与安全问题作战"，语域偏差明显。
- 正确项为何胜出：`cope with sth.` = 应对、处理（problem / issue / difficulty / stress），是中性、专业的处理义；与"计算机科学新领域"的学术语域一致。
- 可迁移规则：**看宾语定搭配：issue / problem / difficulty / stress → cope with / deal with；enemy / crime / poverty → fight against；new environment → adapt to；demand / request → call for。**
