# 2013 完形填空 语法笔记（无现金社会）

> 范围：只收本篇真正承载空格或陷阱的结构，不做全文句法标注。纯搭配见 [[固定搭配与词组笔记]]。

### 第 1 段首句：Given 引导的条件 + in which 定语从句

`Given the advantages of electronic money, you might think that we would move quickly to the cashless society in which all payments are made electronically.`

- `Given + 名词` = "鉴于、考虑到"，是分词转化来的介词性结构，不是被动语态，也不是"被给予"。
- `the cashless society in which all payments are made electronically`：`介词 + which` 引导定语从句，先行词是 society；`in which` 还原为 `in the society`。
- `you might think that …`：that 引导宾语从句，从句内是 `would move`，表推测性将来。

### 第 1 空：连接副词 However 的句法位置与对比框架

`【1 However】, a true cashless society is probably not around the corner.`

- 句法：however 是**连接副词**，不是连词，不能直接连接两个分句，必须用逗号与主句隔开；此处位于句首 + 逗号，正是其典型位置。
- 语义：前句说"你也许认为我们会很快进入无现金社会"，本句说"真正的无现金社会大概还没近在眼前"，两句方向相反 → 转折。
- 排除：Moreover 递进（同向），Therefore 因果（前句不是原因），Otherwise 否则（需前文有条件假设）。

### 第 2 空：have been + 表语 around + for 时间

`predictions have been 【2 around】 for two decades but have not yet come to fruition`

- `be around` = 存在、流传、还在；around 是副词，作表语（类似 be here / be there）。
- 时态：`have been … for two decades` 现在完成时，表"持续二十年"，`but` 引出与"still exist"相反的事实：尚未实现。
- 陷阱：把 around 读成方位"在周围"，或把 over 读成"结束了"，都会让 but 前后自相矛盾。

### 第 4 空：only to do 表出乎意料的结果

`Business Week predicted in 1975 that … , only to 【4 reverse】 itself several years later.`

- `only to + 动词原形` 是不定式作结果状语，固定表"结果却（出乎意料地）……"，前面常是完整分句。
- 语义主体是 Business Week（刊物），`reverse itself` = 自我推翻（把先前的预测反转）。
- 排除：reward 奖励（主语须是人）、resist 抵制（需宾语）、resume 恢复（需中断过的东西）。

### 第 5 空：so + adj. + in doing

`Why has the movement … been so 【5 slow】 in coming?`

- `be slow in doing sth.` = 做某事迟缓；`in coming` 是介词短语，说明"在到来的过程中"。
- `so` 修饰形容词，构成疑问句 `Why has … been so …?`，回答指向第 2、3 段的 four factors。
- 排除：silent（沉默，主语须能发声）、sudden（突然，与 two decades 的时间跨度矛盾）、steady（稳定，褒义，与"迟迟不来"的语气相反）。

### 第 6 空：work against + 名词

`several factors work 【6 against】 the disappearance of the paper system`

- `work against sth.` = 不利于、阻碍某事；`work for` = 有利于。此处主语是 factors（因素），不是人。
- `the disappearance of the paper system` 是动名词结构的名词化：paper system 的消失，正是电子货币想推动却受阻的目标。

### 第 7 空：it is + adj. + to do 形式主语

`it is very 【7 expensive】 to set up the computer, card reader, and telecommunications networks …`

- `it` 是形式主语，真正主语是 `to set up …`；形容词描述的是"搭建"这件事的成本，不是设备本身。
- `necessary to make electronic money the dominant form of payment` 是形容词短语后置修饰 networks。

### 第 8 空：make + 宾语 + 名词（宾补）

`necessary to make electronic money the 【8 dominant】 form of payment`

- `make A B` = 使 A 成为 B，B 是名词作宾语补足语，前面不加冠词以外的限定词。
- 与 `the dominant form` 呼应：dominant 是"占主导地位的"，与上句 `more efficient` 的推广诉求一致。
- 排除：temporary（临时）与"necessary to make"的长期目标矛盾；original（最初）与"设网使其成为主流"的递进语义不符。

### 第 9 空：have the advantage that 同位语从句

`paper checks have the advantage that they 【9 provide】 receipts`

- `that` 引导**同位语从句**，说明 advantage 的具体内容，that 在从句中不作成分、不可省略。
- 从句主谓：they（= paper checks）provide receipts，一般现在时，陈述功能。
- 同一名词后接同位语从句的常见词：fact / idea / belief / advantage / evidence / hope。

### 第 11 空：It takes + 时间段 + before 从句

`it takes several days 【11 before】 a check is cashed and funds are withdrawn from the issuer's account`

- 句型：`It takes (sb.) + 时间 + before + 从句` = "过……（时间）才……"；before 从句用一般现在时表将来。
- 逻辑：先"过几天"，再"支票兑现、资金划出" → 时间先后，不能换成 when（同时发生）或 since（自从）。
- `it` 同样是形式主语，真正主语是 before 从句所描述的过程。

### 第 12 空：被动语态 funds are withdrawn

`funds are 【12 withdrawn】 from the issuer's account`

- `funds` 与 withdraw 是被动关系（资金被划出），由 `are + 过去分词` 构成，与前面的 `a check is cashed` 并列在同一时间状语从句里。
- 排除：kept（留存，与"划出"方向相反）、borrowed（借入，主语应是借入方）、released（释放，用于人质、气体、新闻，不与 account 搭配）。

### 第 13 空：Because 引导原因状语从句

`【13 Because】 electronic payments are immediate, they eliminate the float for the consumer.`

- 主从结构：Because 从句说明原因（电子支付即时），主句给出结果（取消浮存期）；逗号分隔。
- 主句 `they` 指 electronic payments，与从句主语一致。
- 排除：Though 让步（会变成"尽管即时，却取消了浮存期"，逻辑打架）、Unless 除非（否定条件）、Until 直到（时间）。

### 第 15 空：过去分词作后置定语

`to alter information 【15 stored】 there`

- `information stored there` = `information which is stored there`；information 与 store 是被动关系，故用过去分词，不能用现在分词 storing。
- `there` 指前面的 computer database。
- 陷阱：把空处当成谓语，就会误选 analyzed / displayed 等过去式形式；实际本句谓语已是 `has been able to access … and to alter`。

### 第 16 空：双重否定 not an uncommon + 名词

`The fact that this is not an 【16 uncommon】 occurrence`

- `not + 否定词缀形容词` = 肯定：not uncommon = common（并非罕见）。
- `The fact that … means that …`：第一个 that 是同位语从句（说明 fact），第二个 that 是宾语从句（means 的宾语）。
- 排除：unsafe（不安全的，不能修饰 occurrence）、unnatural（不自然的，与"黑客事件频发"的证据无关）、unclear（不清楚，与 occurrence 搭配不成立）。

### 第 17 空：be able to 后并列两个动词原形

`might be able to access bank accounts … and 【17 steal】 from someone else's accounts`

- `be able to + do` 是固定结构，and 并列 access 与 steal，两者共用 `be able to`，故空处必须是动词原形。
- `steal from sb.'s account` = 从某人账户盗取；steal 的宾语是"被偷的东西"，不是"人/账户"（那是 rob sb. of sth.）。
- 排除：choose 选择（需宾语）、benefit 受益（benefit from 才通，但与"不诚实的人"语气相反）、return 归还（方向相反）。

### 第 18 空：动名词主语 + of 短语作定语

`The 【18 prevention】 of this type of fraud is no easy task`

- 主语中心词是 prevention（动名词化的名词），`of this type of fraud` 限定"防范的对象"；谓语 is，与单数主语一致。
- `no easy task` = 绝非易事，是对难度的强调，提示空处应是"防范"而非"考虑/辩解"。
- 排除：consideration 考虑（"考虑欺诈"不是一项 task）、manipulation 操纵（与"防诈"方向相反）、justification 辩解（语义不通）。

### 第 19 空：不定式作目的状语

`a new field of computer science is developing to 【19 cope with】 security issues`

- `to do` 作目的状语：新领域发展，目的是应对安全问题。
- `cope with sth.` = 应对、处理（问题、困难）；`deal with` 同义；`fight against` 多接 crime / poverty / an enemy 这类"对手"，不接 issues。

### 第 20 空：that 定语从句 + 主谓一致

`leaves an electronic 【20 trail】 that contains a large amount of personal data`

- `that contains …` 是定语从句，先行词 trail（单数），从句谓语用 contains；`a large amount of + 不可数名词`（data 此处作不可数集合）。
- `leave a trail` = 留下痕迹；与后句 `access these data` 形成"痕迹—数据—隐私"的链条。
- 排除：chunk（大块）、chip（芯片；`electronic chip` 是硬件，不是"留下的东西"）、path（路径，多指行走/发展路线，不含"被动留下"义）。

### 第 3 段末：thereby + 现在分词表结果

`… might be able to access these data, thereby violating our privacy.`

- `thereby + doing` 是分词短语作结果状语，主语与主句一致（government, employers, and marketers）。
- 与前文 `access these data` 构成"行为 → 后果"链，是全篇收束句。
