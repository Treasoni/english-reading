# 2015 完形 Talking to Strangers 固定搭配与词组

纯语法结构见 [[intermediate/2015-cloze-talking-to-strangers/grammar-notes]] 与 [[语法总结笔记]]。

## 主题词

| 表达 | 含义 | 语境提示 |
|---|---|---|
| stranger | 陌生人 | 与朋友、熟人 `friends and acquaintances` 对照 |
| social advance | 社交示好；主动攀谈 | 本文特指无恶意的主动接触 |
| social connection | 社会联结；人际联系 | 文章最后给出的积极结果 |
| commuter | 通勤者 | 实验参与者；乘火车通勤的人 |
| security blanket | 安全毯；心理上的慰藉 | 比喻手机让人免于面对社交不安 |
| band-aid | 创可贴 | `rip off the band-aid` 比喻跨过心理门槛、直接尝试 |

## 高频固定搭配

| 搭配 | 含义 / 用法 | 本篇考点 |
|---|---|---|
| 📌 there is much to be gained from doing sth | 做某事大有收获 | 第 2 空：`there's much to be gained from talking`；`little/nothing` 改变“收益很多”的正向判断，`another` 不合结构 |
| 📌 be plugged into sth | 插入/接入……；（此处）沉浸于手机 | 第 3 空：`plugged into your phone` 描述低头看手机的状态；其余选项不能与 `into your phone` 构成同义表达 |
| 📌 send the message (that...) | 发出……信号；表达……意思 | 第 4 空：`send the message` 后接直接引语，表示手机姿态传达“别靠近我” |
| 📌 hide behind sth | 躲在……后面 | 第 5 空：`hide behind our screens` 是屏幕遮挡社交接触的隐喻；`under/beyond/from` 方向或语义不合 |
| 📌 misinterpret A as B | 把 A 误解为 B | 第 6 空：`advances will be misinterpreted as “weird”`；misapply 用错/滥用方法，mismatch 不这样支配 as 补语 |
| 📌 turn to sth | 转向/求助于…… | 第 10 空：`turn to our phones`；`attend/point/take to` 均不能表达遇到不安时求助手机 |
| 📌 thrive off of sth | 依靠……而茁壮成长/发展 | 第 19 空附近：人类依靠社会联系而繁荣发展；此处 `since` 引出原因 |
| 📌 It’s that simple | 道理就是这么简单 | 第 20 空：冒号后给出简单结论，`that` 修饰形容词 `simple` |

## 动词搭配与干扰项辨析

| 正确表达 | 关键搭配/框架 | 干扰项为什么不合适 |
|---|---|---|
| 📌 `feel anxious`（第 9 空） | feel + 形容词 | `comfortable/confident` 与 `uneasiness` 的语义方向相反；`angry` 表愤怒，不是陌生人社交时的典型不安 |
| 📌 `protect sb from sth`（第 11 空） | protect + 人 + from + 危险/伤害 | `more dangerous` 与手机提供保护、躲避风险的语义吻合；mysterious / violent / boring 都不等于感知到的危险 |
| 📌 `hurt so bad`（第 12 空） | 口语表达“没那么糟/没那么难受” | `it doesn't hurt so bad` 表示尝试后并不如预想糟；resist、bend、decay 在句法上虽能接，但语义不通 |
| 📌 `start a conversation`（第 13 空） | start + conversation | lecture、debate、negotiation 分别为讲座、辩论、谈判；实验要求的是普通社交交谈 |
| 📌 `fellow passengers`（第 14 空） | fellow + 身份名词，表示同伴/同类 | commuter 与 passengers 对应同车乘客；employees、researchers、trainees 与实验场景不相符 |
| 📌 `predict how ...`（第 15 空） | predict + 间接疑问句 | reveal（揭示）、choose（选择）、design（设计）均不表示预测感受；语法结构详见 [[intermediate/2015-cloze-talking-to-strangers/grammar-notes]] |
| 📌 `one's ride`（第 16 空） | ride 指乘车旅程 | commuters 预想自己的乘车过程；voyage 是航海/长途旅程，walk 是步行，flight 是飞行 |
| 📌 `go through with sth`（第 17 空） | 坚持做完；着手并完成某事 | `go through with the experiment` 表示实际参加/完成实验；`do away with` 是废除，`catch up with` 是赶上，`put up with` 是忍受 |
| 📌 `In fact`（第 18 空） | 事实上；用事实补强前述结论 | `In turn` 表示相应地/轮流，`In particular` 表示尤其，`In consequence` 表示因此；此处是在补充实验实际发现 |
| 📌 `since`（第 19 空） | 因为；引导原因状语从句 | `human beings thrive...` 为“通勤交谈令人愉快”提供原因；unless 是除非，if 是如果，whereas 是而/然而 |

## 速记卡片

| 段落 | 信号词 / 结构 | 记忆线索 |
|---|---|---|
| 1 | `cling to their phones` | 没有手机信号 `signal` 也盯手机，呈现回避陌生人的状态 |
| 2 | `to be gained` / `sends the ...` | 与陌生人交谈有很多收获 `much`，手机发出 `message` |
| 3 | `hide ... our screens` | 躲在屏幕后：`behind` |
| 4 | `fear ... as “weird”` / `fear ...` | 善意接近被误解：`misinterpreted`；担心被评判：`judged` |
| 5 | `inherently ...` / `uneasiness` / `protect ... from` | 陌生即不熟悉 `unfamiliar`，引发焦虑 `anxious`，于是求助手机 `turn`，躲避危险 `dangerous` |
| 6 | `doesn't ... so bad` / experiment | 并没那么糟 `hurt`；开始交谈 `conversation`，与乘客交流；预测 `predict` 旅程 `ride`；最终做完实验 `went through` |
| 7 | `... more enjoyable` / `makes sense` / `It's that ...` | 事实补强 `In fact`，原因 `since`，结论简单 `simple` |
